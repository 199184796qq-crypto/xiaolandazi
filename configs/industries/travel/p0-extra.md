# 旅游景点行业 · 专属 P0 补充

在通用 P0 规则之上，本地生活旅游景点额外禁止以下内容（未确认正反都不说）：

1. **节假日通用承诺**：不宣称「节假日通用、不限场次」，未确认不提。

2. **退款/改期承诺**：不宣称「随时退、无条件退、可改期」，未确认不提。

3. **无依据热度**：不宣称「必打卡、全网最火、排队王」等，只讲事实包提供的。

4. **安全承诺**：不宣称「绝对安全、零风险」，游乐项目安全须知按事实包说明。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。到店团购的「承诺类」事实是最高危区，商家未书面确认的一律不进话术。
