# 服装行业 · 卖点挖掘维度

根据正式事实包（商品卡 + 活动福利 + 事实依据），判定商品属于服装行业后，严格套用下面的「核心必查维度」。只要事实包提供了对应信息，每个维度都要**各自独立成卖点**，不得合并进「其它」或直接省略。多个链接/商品时，每个商品都要有对应讲解角度。

## 通用维度（服装行业也必须覆盖）

价格算账（原价/现价/活动价的可核算差价）、规格与选购（尺码/颜色/怎么选）、物流发货（快递/时效/包邮）、售后保障（退换货是服装重点/运费承担）、品牌/资质/来源（品牌历史/产地/证书）、目标人群与痛点（谁穿/解决什么顾虑）、洗护方式（怎么洗/怎么保养）。

## 服装专属维度（逐个独立成卖点）

1. **面料材质**：棉/麻/丝/毛/化纤等成分、克重、手感、透气性（仅限事实包有依据），单独成卖点；
2. **版型与尺码**：版型（修身/宽松）、尺码范围、怎么选码、上身效果，单独成卖点；
3. **做工工艺**：缝制、锁边、辅料、工艺细节，单独成卖点；
4. **穿着体验**：舒适、垂感、保暖、透气等（仅限已确认），单独成卖点；
5. **洗护保养**：机洗/手洗、是否褪色/缩水、保养方式，单独成卖点；
6. **适用场景/季节**：通勤/休闲/约会、春夏秋冬季节适配，单独成卖点；
7. **搭配建议**：怎么搭、配什么下装/外套，单独成卖点；
8. **资质/安全**：面料检测、A类/婴幼儿级、环保（仅限事实包有依据），单独成卖点。

## 判定规则

1. 只套用事实包能够支持的维度；某维度事实包没有对应信息时跳过，不得补写、不得编造。
2. 事实包明显属于服装行业时，上述通用维度 + 专属维度一起构成本轮「核心必查维度」。
3. 事实包有多个商品/链接时，每个商品都必须有对应的讲解角度。
4. 卖点总数目标：事实丰富时生成 8~12 个卖点，每个卖点 5~8 个角度。面料、版型、做工这些服装核心维度不得合并或省略。
