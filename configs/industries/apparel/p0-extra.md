# 服装鞋帽行业 · 专属 P0 补充

在通用 P0 规则之上，服装鞋帽行业额外禁止以下内容（未确认正反都不说）：

1. **绝对化品质承诺**：不宣称「零甲醛、绝对不褪色、永不缩水、100%不起球」，除非有检测依据；改为可核实的说法。

2. **材质/成分虚标**：面料成分、克重、等级（A类/婴幼儿级）须与检测一致，不虚标、不张冠李戴。

3. **医疗/保健功效**：不宣称「抗菌治病、保暖养生」等功效，服装按普通商品表述。

4. **无依据的销量/口碑**：不说「全网第一、销量最高」等未确认排名。

5. **无依据的稀缺/限时**：不说「限量、最后 X 件、马上断货」等未确认话术。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。
