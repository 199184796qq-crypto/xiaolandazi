# 丽人美业行业 · 专属 P0 补充

在通用 P0 规则之上，本地生活丽人美业额外禁止以下内容（未确认正反都不说）：

1. **效果夸大**：不宣称「一次见效、永久保持、无副作用」，效果类宣称须有依据。

2. **医疗功效**：不宣称「治疗、祛斑、祛痘」等医疗功效，未确认不提。

3. **产品资质虚标**：使用产品、品牌、资质只讲事实包确认的。

4. **无隐形消费**：不宣称「无附加消费」，除非有确认依据。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。到店团购的「承诺类」事实是最高危区，商家未书面确认的一律不进话术。
