# 婚庆摄影行业 · 专属 P0 补充

在通用 P0 规则之上，本地生活婚庆摄影额外禁止以下内容（未确认正反都不说）：

1. **效果承诺**：不宣称「张张大片、包满意」等，效果须以样片为依据。

2. **价格虚标**：套系价格、附加费用须与事实包一致，不虚标、不隐瞒。

3. **档期承诺**：不宣称「随时有档期、指定日期」，未确认不提。

4. **退款/改期**：不宣称「无条件退、随便改期」，未确认不提。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。到店团购的「承诺类」事实是最高危区，商家未书面确认的一律不进话术。
