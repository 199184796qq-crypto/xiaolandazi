# 运动健身行业 · 专属 P0 补充

在通用 P0 规则之上，本地生活运动健身额外禁止以下内容（未确认正反都不说）：

1. **效果夸大**：不宣称「月瘦 X 斤、包瘦、包练出马甲线」等效果承诺。

2. **医疗/康复功效**：不宣称「治疗、康复」等医疗功效，未确认不提。

3. **资质虚标**：教练资质、认证只讲事实包确认的。

4. **退款/转让承诺**：不宣称「随时退、可转让」，未确认不提。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。到店团购的「承诺类」事实是最高危区，商家未书面确认的一律不进话术。
