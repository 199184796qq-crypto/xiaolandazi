# 生鲜果蔬行业 · 专属 P0 补充

在通用 P0 规则之上，生鲜果蔬行业额外禁止以下内容（未确认正反都不说）：

1. **新鲜/有机绝对化**：不宣称「绝对新鲜、现摘现发、当天到、无农残、有机认证」，除非事实包提供对应检测/认证依据。

2. **治疗/保健功效**：不宣称「养生、排毒、增强免疫」等功效，生鲜按普通食品表述。

3. **无依据的产地/年份**：产地、当季、年份只讲事实包明确提供的，不延伸、不美化。

4. **无依据的稀缺/限时**：不说「限量 X 份、马上断货、最后一批」等未确认的紧迫话术。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。
