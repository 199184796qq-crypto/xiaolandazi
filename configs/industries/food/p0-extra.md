# 食品行业 · 专属 P0 补充

在通用 P0 规则之上，食品行业额外禁止以下内容（未确认正反都不说）：

1. **医疗/保健功效宣称**：不宣称「降血糖、降血脂、抗癌、补肾、养胃、增强免疫力、减肥」等任何治疗或保健功效，除非事实包提供了对应资质与检测依据。食品不是药品，一律按普通食品表述。

2. **绝对化安全/品质承诺**：不说「零添加、纯天然、无防腐剂、绝对新鲜、100% 无残留」等，除非事实包有对应检测/资质依据；改为可核实的说法（如「配料表只有 X」「保质期 X 天」）。

3. **特殊人群功效**：不宣称「孕妇/婴幼儿/老人/病人专用、适合 X 人群」等功效指向，未确认的一律不提。

4. **无依据的稀缺/限时**：不说「限量 X 份、最后 X 单、马上断货」等未确认的紧迫话术。

5. **无依据的产地/年份/资质**：产地、年份、非遗、老字号等，只讲事实包明确提供的，不延伸、不美化。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。
