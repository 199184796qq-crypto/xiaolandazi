# 食品行业 · 卖点挖掘维度

根据正式事实包（商品卡 + 活动福利 + 事实依据），判定商品属于食品行业后，严格套用下面的「核心必查维度」。只要事实包提供了对应信息，每个维度都要**各自独立成卖点**，不得合并进「其它」或直接省略。多个链接/商品时，每个商品都要有对应讲解角度，主推、礼品装、尝鲜装等都不能遗漏。

## 通用维度（食品行业也必须覆盖）

价格算账（原价/现价/活动价/组合价的可核算差价）、规格与选购（克重/数量/口味怎么选）、物流发货（快递/时效/包邮/配送范围）、售后保障（退换/坏损赔付/运费承担）、品牌/资质/来源（品牌历史/门店/产地/证书/检测）、目标人群与痛点（谁需要/解决什么顾虑）、使用/保存方式（怎么吃/怎么存/怎么复热）。

## 食品专属维度（逐个独立成卖点）

1. **口感风味**：肉紧、有嚼头、油少皮薄、无腥味、鲜甜、酥脆等口感描述，单独成卖点；
2. **配料成分**：原料、配料、添加剂、是否真材实料，单独成卖点；
3. **制作/加工工艺**：老卤慢炖、油炸、裹红油、锁汁定型等工序，单独成卖点并逐个工序展开角度；
4. **原料产地**：原料来源、产地环境、地域饮食文化，单独成卖点；
5. **营养构成**：蛋白质、脂肪等营养成分（仅限事实包有依据的），单独成卖点；
6. **保存与复热方式**：常温/冷藏保存期限、开封后处理、怎么复热，单独成卖点；
7. **资质/认证**：非遗技艺、证书、级别、检测报告（仅限事实包有依据的），单独成卖点；
8. **品牌/地域饮食文化**：品牌历史、产地环境、地域饮食文化，单独成卖点；
9. **送礼/节日场景**：礼品包装、送礼对象、食用场景，单独成卖点。

## 判定规则

1. 只套用事实包能够支持的维度；某维度事实包没有对应信息时跳过，不得补写、不得编造。
2. 事实包明显属于食品行业时，上述通用维度 + 专属维度一起构成本轮「核心必查维度」。
3. 事实包有多个商品/链接时，每个商品都必须有对应的讲解角度，主推、礼品装、尝鲜装都不能遗漏。
4. 卖点总数目标：事实丰富时生成 10~15 个卖点，每个卖点 5~10 个角度。宁可卖点少而角度足，也不要把口感、工艺、营养等核心维度合并或省略。
