# 宠物服务行业 · 专属 P0 补充

在通用 P0 规则之上，本地生活宠物服务额外禁止以下内容（未确认正反都不说）：

1. **医疗功效**：不宣称「治病、驱虫、保健」等，除非有兽药/医疗资质依据。

2. **绝对安全承诺**：不宣称「绝对安全、零风险、不会应激」，未确认不提。

3. **资质虚标**：兽医资质、医疗资质只讲事实包确认的。

4. **无依据口碑**：不宣称「最好、最专业」等，只讲事实包提供的。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。到店团购的「承诺类」事实是最高危区，商家未书面确认的一律不进话术。
