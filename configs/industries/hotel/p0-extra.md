# 酒店住宿行业 · 专属 P0 补充

在通用 P0 规则之上，本地生活酒店住宿额外禁止以下内容（未确认正反都不说）：

1. **无隐形消费承诺**：不宣称「无隐形消费、到店不加价」，除非有确认依据。

2. **节假日/时段通用**：不宣称「节假日通用、旺季可用」，未确认不提。

3. **退款/过期承诺**：不宣称「过期可退、随时退、无条件退」，未确认不提。

4. **无依据排名**：不宣称「最好、评分最高、最舒适」等，只讲事实包提供的评分与好评。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。到店团购的「承诺类」事实是最高危区，商家未书面确认的一律不进话术。
