# 教育培训行业 · 专属 P0 补充

在通用 P0 规则之上，本地生活教育培训额外禁止以下内容（未确认正反都不说）：

1. **效果承诺**：不宣称「包过、提分、保录取、包会」等效果承诺。

2. **资质虚标**：办学资质、师资、认证只讲事实包确认的。

3. **升学/就业保证**：不宣称「保送、包就业」等，未确认不提。

4. **无依据口碑**：不宣称「最好、通过率第一」等，只讲事实包提供的。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。到店团购的「承诺类」事实是最高危区，商家未书面确认的一律不进话术。
