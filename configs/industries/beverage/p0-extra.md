# 酒水饮料行业 · 专属 P0 补充

在通用 P0 规则之上，酒水饮料行业额外禁止以下内容（未确认正反都不说）：

1. **医疗/保健功效**：不宣称「解酒、助眠、养生、降三高」等功效，酒水饮料按普通食品表述。

2. **未成年人相关**：不出现诱导未成年饮酒、不宣称「适合青少年」等表述。

3. **绝对化品质承诺**：不说「零添加、纯天然、绝对安全」，除非事实包有对应检测依据。

4. **无依据的年份/产地/度数**：年份、产地、度数、等级只讲事实包明确提供的，不延伸。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。
