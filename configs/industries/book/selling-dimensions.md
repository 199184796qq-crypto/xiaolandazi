# 图书文教行业 · 卖点挖掘维度

根据正式事实包（商品卡 + 活动福利 + 事实依据），判定商品属于图书文教行业后，严格套用下面的「核心必查维度」。只要事实包提供了对应信息，每个维度都要**各自独立成卖点**，不得合并进「其它」或直接省略。多个链接/商品时，每个商品都要有对应讲解角度，主推、组合装、尝鲜装等都不能遗漏。

## 通用维度（图书文教行业也必须覆盖）

价格算账（原价/现价/活动价/组合价的可核算差价）、规格与选购（规格/型号/怎么选）、物流发货（快递/时效/包邮/配送范围）、售后保障（退换/赔付/运费承担）、品牌/资质/来源（品牌历史/产地/证书/检测）、目标人群与痛点（谁需要/解决什么顾虑）、使用/保存方式（怎么用/怎么保存）。

## 图书文教专属维度（逐个独立成卖点）

1. **内容简介**：内容主题、亮点、适合谁读，单独成卖点；
2. **作者与出版社**：作者、出版社、专业背景，单独成卖点；
3. **适读年龄**：适读年龄、难度分级，单独成卖点；
4. **版本与装帧**：版本、装帧、纸张、配套，单独成卖点；
5. **赠品与配套**：赠品、配套资料、音视频，单独成卖点；
6. **规格与选购**：册数、开本、怎么选，单独成卖点；
7. **品牌/资质**：出版社资质、获奖（仅讲确认的），单独成卖点；

## 判定规则

1. 只套用事实包能够支持的维度；某维度事实包没有对应信息时跳过，不得补写、不得编造。
2. 事实包明显属于图书文教行业时，上述通用维度 + 专属维度一起构成本轮「核心必查维度」。
3. 事实包有多个商品/链接时，每个商品都必须有对应的讲解角度，主推、组合装、尝鲜装都不能遗漏。
4. 事实丰富时生成 8~12 个卖点，每个卖点 5~8 个角度。内容、作者、适读年龄这些核心维度不得合并或省略。
