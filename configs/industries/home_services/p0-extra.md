# 家政家装行业 · 专属 P0 补充

在通用 P0 规则之上，本地生活家政家装额外禁止以下内容（未确认正反都不说）：

1. **人员背景虚标**：人员资质、背景、持证只讲事实包确认的。

2. **效果承诺**：不宣称「一次保洁永无灰尘、修好为止」等，除非有确认保障。

3. **环保绝对化**：不宣称「零甲醛、绝对环保」，除非有检测报告。

4. **赔付/保障夸大**：赔付、保障规则须与事实包一致。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。到店团购的「承诺类」事实是最高危区，商家未书面确认的一律不进话术。
