# 餐饮（到店）行业 · 专属 P0 补充

在通用 P0 规则之上，本地生活到店团购额外禁止以下内容（未确认正反都不说）：

1. **无隐形消费承诺**：不宣称「无隐形消费、到店不加价、无任何附加费」，除非事实包明确提供了该承诺依据。

2. **节假日/时段通用承诺**：不宣称「节假日通用、周末通用、高峰期可用」，未确认的一律不提。

3. **退款/过期承诺**：不宣称「过期可退、随时退、无条件退」，退款政策未确认的不提。

4. **不限量/随时有位承诺**：不宣称「不限量、随时有位、不用排队、随到随用」，未确认的不提。

5. **无依据的排名/口碑**：不宣称「全市第一、最好吃、评分最高、排队王」等，只讲事实包提供的评分、好评与回头客信息。

6. **功效类承诺**：不宣称「滋补、养生、调理」等功效（餐饮不是药品/保健品），只讲口味、食材、工艺。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。到店团购的「承诺类」事实是最高危区，商家未书面确认的一律不进话术。
