# 亲子玩乐行业 · 专属 P0 补充

在通用 P0 规则之上，本地生活亲子玩乐额外禁止以下内容（未确认正反都不说）：

1. **绝对安全承诺**：不宣称「绝对安全、零风险、不会受伤」，除非有确认依据。

2. **医疗/发育功效**：不宣称「开发智力、促进发育」等，未确认不提。

3. **节假日通用**：不宣称「节假日通用、随时可用」，未确认不提。

4. **无依据排名**：不宣称「最好玩、最热门」等，只讲事实包提供的。

补充说明：以上补充只增不减，与通用 P0 的四层结构（必说/可说/不提/改写）叠加执行；违反任意一条即触发【改写】或【不提】。到店团购的「承诺类」事实是最高危区，商家未书面确认的一律不进话术。
