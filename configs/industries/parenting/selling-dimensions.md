# 亲子玩乐行业 · 卖点挖掘维度

根据正式事实包（套餐卡/项目卡 + 团购福利 + 事实依据），判定属于「本地生活 · 亲子玩乐」行业后，严格套用下面的「核心必查维度」。只要事实包提供了对应信息，每个维度都要**各自独立成卖点**，不得合并进「其它」或直接省略。一个方案有多个套餐/项目时，每个都要有对应讲解角度。

## 核心必查维度（逐个独立成卖点）

1. **价格算账**：团购价 vs 现场价、人均、省多少，单独成卖点；
2. **游乐项目**：项目、玩法、套餐包含什么，单独成卖点；
3. **适龄范围**：适龄、身高限制、陪同要求，单独成卖点；
4. **安全防护**：安全措施、防护、保障（仅已确认），单独成卖点；
5. **设施环境**：场地、环境、卫生、配套，单独成卖点；
6. **预约与使用**：需不需预约、有效期、营业时间，单独成卖点；
7. **核销方式**：到店出示券码、附加消费（仅已确认），单独成卖点；
8. **口碑与评价**：好评、评分、回头客，单独成卖点；
9. **场景适配**：周末遛娃/生日/家庭出游，单独成卖点；

## 判定规则

1. 只套用事实包能够支持的维度；某维度事实包没有对应信息时跳过，不得补写、不得编造。
2. 事实包明显属于亲子玩乐行业时，上述维度构成本轮「核心必查维度」。
3. 事实包有多个套餐/项目/链接时，每个都必须有对应的讲解角度，主推、尝鲜都不能遗漏。
4. 事实丰富时生成 8~12 个卖点，每个卖点 5~8 个角度。项目、适龄、安全、口碑这些核心维度不得合并或省略。
5. **到店团购的铁律**：只讲「到店体验」，不涉及「外卖/快递配送」；配送范围、时效、打包、配送费属于外卖或电商物流，本行业不提。
