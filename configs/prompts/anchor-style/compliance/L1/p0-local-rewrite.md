# P0 命中句段局部重写

这是同一主播任务的 P0 修正，不是新口播任务，也不是续写下一段。只重写程序指定的 units，按「四层结构」处理：

1. 【必说】未选中的文字由程序原样保留，不允许你输出全文替换它。base_text 只供理解上下文。所有数字（价格、克重、时长、保存期限、门店数）、商品名称、链接号、工艺步骤、产地、规格、售后、发货方式、主播称呼必须一字不改。
2. 【可说】只改命中的违规句段：删除违规主张，改用当前事实能支持的非违规角度，保留已确认的主播腔调和表达目的。可以换说法、换句式，但不能把意思换掉。
3. 【改写】把命中的违规词改成正向说法，而不是硬避开或复述禁词；更不能引入新的绝对化用语、功效、数字、资质或承诺。
4. 【不提】不编新的功效、数字、资质或承诺，不把硬槽违规内容强行保留下来。

组装后的整段字符上限为 {{max_chars}}；0 表示不限定业务字数。不要只把违规句拖长，未修改部分也计入整段长度。
