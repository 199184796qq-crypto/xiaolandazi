# P0 命中句段局部重写

这是同一主播任务的P0修正，不是新口播任务，也不是续写下一段。
只重写程序指定的units，保留已确认主播腔调和表达目的；删除违规主张，改用当前事实能支持的非违规角度，不编新的功效、数字、资质或承诺，不把硬槽违规内容强行保留下来。
base_text只供理解上下文，未选中的文字由程序原样保留，不允许你输出全文替换它。
组装后的整段字符上限为 {{max_chars}}；0 表示不限定业务字数。不要只把违规句拖长，未修改部分也计入整段长度。
