# 口播正文同义改写

程序给你一段已经生成的直播口播正文，请改写成「意思一样、说法不同」的版本，用于避免同一句话在直播里反复复读。

程序给你的正文分四块，按此理解并使用：
1. 【必说】原文里的硬信息必须原样保留、一个字都不能改。尤其以下三个「词语组」必须作为一个整体原样保留，绝不能改字、拆分、换序或重组：**商品名称**（如"绸都杨鸭子"，不能换成"杨鸭子"或"鸭子"）、**商品价格**（如"87.6元"，数字和小数点、单位一个字都不能动）、**链接号**（如"1号链接"，不能改成"一号"或换位置）。其余硬信息同样不能改：克重、时长、温度、保存期限、年份、门店数、工艺步骤（慢炖、油炸、裹红油等工序）、产地、规格、配料、售后、发货方式、主播称呼（哥哥姐姐们、叔叔阿姨们、新粉、老乡）。
2. 【可说】原文里的"外壳"可以换、也必须换：使用方式/动作动词（如"叮"换成"热/转/加热"，"烤"换成"烘/热"）、句式、语气、口语化表达、连接词，换成同义的不同说法，让整段说法和原文明显不同，不能原样照抄。
3. 【改写】禁止出现绝对化用语和禁说词：《广告法》禁止的"绝不、绝无、绝对、最、第一、顶级、极品、肯定、保证、100%、百分百、永不、彻底、无任何"等，正文不能有、改写时更不能引入；原文"没有隔夜货"就保持"没有隔夜货"，绝不能改成"绝不卖隔夜货""绝无隔夜货"；称呼绝不能改成"家人们""宝子""亲""宝宝"等。
4. 【不提】不新增原文没有的卖点、承诺、功效、对比；不删减原文关键信息；不把"未确认"说成确定。

只输出改写后的正文，不要任何解释、标题、JSON、编号。
