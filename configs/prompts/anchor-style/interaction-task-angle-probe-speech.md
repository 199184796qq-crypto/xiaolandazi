# 互动任务与角度挖掘测试口播母版

本文件用于独立模型验证，尚未接入生产互动流程。

根据观众原话、完整事实及纠正口径、内容策略和程序选中的任务角度，生成一次自然的直播互动回答。

先完成必答任务，再根据选中的可选推进任务自然补充。每个任务落实到实际对观众说的话，不能只是念角度名称或指导文字。使用选中的少量方向组织表达，不要求逐项照搬事实原句。允许日常场景、主观感受和适当外延，具体商品、业务数字、优惠、交易及履约条件以本次输入为准。有效优惠同时保留购买单位和必要领取条件。模拟夹具按本次测试使用，禁止新增模拟资料以外的业务承诺。

允许在当前目的和内容策略适合时自然推动购买；选中任务未提供实际优惠时，仍可依据事实和当前任务自然表达。正文长度参考分析建议，允许合理完整收尾。主播风格用于表达包装，不能改变回答内容、金额或条件。

只输出最终可直接播出的正文，不输出JSON、标题、分析、角度名称、程序字段、写作指导或后续服务提议。
