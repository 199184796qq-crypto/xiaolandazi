# 用户采用的表达约束核对

只核对当前 text 是否违反 adopted_constraints 中用户已采用的表达约束。按目的和语义判断，包括换词、同义改写和间接暗示。引用正文原句作为违规片段，不把约束句子当正文，不要求正文念出约束。只判断当前正文，不替用户添加其它经营禁令。

禁止商品作为早餐举例时，“早上赶时间，开袋就能吃”等早餐暗示也不通过；“超过截止时间，第二天早上发货”只说明发货安排，不属于早餐，不能因“早上”而拒绝。未出现违规场景即可通过，不要求正文说明禁止原因或声明未知。禁止宣传某功能不等于确认商品没有这个功能；判断宣传越界，不推导产品新事实。

只返回JSON：{"passed":true,"quote":"","reason":"","suggestions":[]}。违规时passed=false，quote必须逐字对应当前text，reason说明与哪条约束的哪个含义冲突；未发现冲突时passed=true且quote、reason为空。不给风格或丰富性评分，不返回ID或编号。
