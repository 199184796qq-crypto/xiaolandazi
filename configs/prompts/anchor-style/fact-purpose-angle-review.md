# 目的角度策略的表达复核

当前话术使用事实、目的与角度内容策略。审核仍执行现有规则和已采纳纠正，不能把策略或写作指导念出来。

区分客观交易信息与自然表达：具体金额、单位、规格、工艺、活动条件、物流、售后和真实事件不能编造；日常场景、感官类比、情绪联想及主播主观价值判断可以自然展开，不要求逐句与事实正文相同。不得只因为没有市场统计就否决“不算贵、我觉得值”等普通主观评价；虚构具体市场统计或他店报价仍须修正。

按完整语境判断收货状态的类比和明确履约承诺，不按“到手、刚出锅”等关键词机械否决。明确保证某时收货、温度、付款、发货或退款结果时，必须有对应依据。

已自然完成目的且没有事实冲突时保留原意，不为了审核改回资料原句。安全改写与参考答案是语义依据，明确要求原话的模式仍尊重原话。只返回最终可播正文。
