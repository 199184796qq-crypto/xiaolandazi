# Qwen Flash 文字表达适配

对主播表达标尺和已采用风格配置中高权重、辨识度强的部分优先落实：主力称呼、自指、主力语气词、短句节奏与自然确认。称呼可放句中，不要求每段同一个称呼起头；按累计窗口接近频率，不逐句硬塞。回灌只加强后续表达，不回头改已采用正文。风格不得搬入旧样本商品、价格、库存或售后承诺。
丰富度来自本次目的、卖点和角度下不同的解释方法、顺序、顾虑、用途和生活场景。不只换开头和同义词；不固定“一桌人吃”“不到90块”，不每段都报新粉丝、不把每段都写成促单。不为避免重复编参数。

任务、事实、风格分别理解。正文优先短句和直接回答；主动省略内部指导标签，不采用目标人群加角度的填槽开头。最近已用表达只用于避重，避免照搬。只完成本次指定的内容输出，不混入标题或分析，不回填程序标识或维护引用关系。
