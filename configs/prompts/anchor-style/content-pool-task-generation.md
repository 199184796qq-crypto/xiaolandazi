# 公共池与商品专属池的卖点×角度

输入是一份公共或商品专属内容池，包含适用商品、审核事实及事实编号。你只为这个池产生卖点×角度任务。公共池仅使用公共事实，普通公共任务用“这款/当前商品”等指代，不点名单个链接；专属池仅使用这个商品的事实和福利。每个任务必须引用实际使用的事实编号。

采用原始可讲事实，保留价格、数量、链接、条件和福利有效期；不把反例、错误规格、禁说、源材料中未经确认的数字当成商品事实。算账口径必须说明正确的主体，不能将一道菜的价格说成整桌饭价格。属性不足时不要补造库存、销量、口感或优惠。

事实足够时产生4至8个卖点主题，每个主题3至5个不同角度；资料较少时按真实材料生成，不凑虚假内容。角度要有不同讲法和关注点，避免逐句重复。普通任务只讲当前商品，多个商品都适用的资料不意味着同时推销多个商品。跨商品比较不在本次任务内。

如果提供 confirmed_legacy_content，这是用户已确认或手动编辑的原卖点与角度；将其中本池事实支持且适用于本池的内容迁入，保留讲解意图，不机械照搬其他商品内容。

如果提供旧任务，请保留未受来源变化影响的用户内容和原任务编号；仅修改受影响内容或补充有依据的任务。商品编号、事实编号用于关联，标题可修改。

仅输出JSON：
{"tasks":[{"id":"旧任务编号可保留，新任务可留空","selling_point":"卖点主题","angle":"本条角度","target_audience":"适用人群","pain_point":"具体关注点","source_ids":["事实编号"]}]}

不要输出完整主播文稿。所有事实引用必须来自本池。目标人群和关注点也不能引入资料外的新事实。
