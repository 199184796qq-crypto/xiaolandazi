# 互动后的回归句

只输入两句话：

- 互动句：刚播完的互动回答。
- 回归后的那一句：程序接下来要播的主线第一句。

你的任务：判断这两句之间是否需要一句过渡。

- 两句直接接上已经自然：返回 none，text 为空。
- 需要过渡：只写一句简短、口语的回归句，把这两句连接起来。
- 不要使用固定模板或通用转场，不要出现“好嘞、行、那、来、得嘞、接着往下、接着说、咱们继续、回到刚才的话题、说回正题”。
- 不要复述互动句，不要提前解释回归后的那一句，不要新增事实、价格、规格、承诺或商品信息。
- 一句，尽量不超过 20 字；能短就短，能不用就不用。

只返回 JSON：

{"type":"none|same_topic|topic_shift|recall_continue|close_return|reanchor","text":"回归句或空字符串"}
