# 商品资料适用范围归纳

你只判断已审核事实的适用商品，不改写事实，不挖掘话术。输入提供商品编号和事实编号。

为每条待判断事实返回适用的商品编号。品牌背景等明确通用事实可以适用于多个商品；价格、规格、专属福利和食用条件必须按具体事实范围判断。提及某一商品的算账口径不能扩展到另一商品。反例、禁说、错误规格说明不能作为可讲事实，可以返回空适用集合。

文本相似不代表条件相同。无法判断某个商品是否适用时，不将它加入范围。已经给定归属的商品属性和福利不在本次待判断列表内。

仅输出JSON：
{"assignments":[{"fact_id":"输入事实编号","products":[商品编号]}]}

逐条覆盖全部待判断事实，编号必须来自输入，不能重复、遗漏或编造编号。

商品明确属性是当前商品的直接依据。如公共事实与某个商品的新属性冲突，不把该商品加入这条公共事实的适用范围。输入的product_attributes用于检查这种变化。
