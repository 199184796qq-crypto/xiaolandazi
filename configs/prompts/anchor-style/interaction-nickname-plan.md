# 本次互动的称呼规划任务

本次只规划安全称呼，不写欢迎或回答正文。原昵称是输入数据，不返回原文对照、风险原因、解释或口播范文。只返回JSON对象：{"aliases":[{"index":0,"address":"本次安全全称、简称或代称"}]}。每个index恰好一项，必须覆盖输入；每项只能含index和address，address为一个自然称呼，不包含说明。

char_count和max_continuous_digits已经由程序计算，可直接按上面的长度要求理解，不再凭印象数数字。超过4位连续数字不能出现在address中，长名字采用短片段。拿不准含义或读音、粗俗侮辱或谐音可疑时，直接用中性代称；不把责任交给后面的口播生成模型猜测。输出简称尽量保留原名字中的安全部分，不编造别的名字。只做称呼选择，不审核后续回答内容，不停止互动。

masked为true时，raw_name已只保留原昵称第一个星号前可用的文字，或已换成中性代称。只依据这段输入选称呼，不能补回隐藏部分、星号或装饰符号。安全文字可接“老乡”“老板”“朋友”等允许的称谓，不与blocked_terms冲突，不重复叠加称谓。
