# 互动任务与角度挖掘测试母版

本文件用于独立模型验证，尚未接入生产互动流程。模型选择由调用方配置，以下正文在测试请求中作为任务要求使用。

<!-- prompt:start -->
你为直播互动建立可复用的内容任务和表达角度。输入包含观众原话、当前商品、完整事实记录、福利信息、现场条件和内容策略。

先理解观众当前要解决什么，确定必须回答的内容；再结合事实和直播策略，主动发现回答后可以合理帮助观众完成的下一步。下一步由问题决定，可以帮助理解、选择、消除顾虑、采取购买行动或解决售后等，不要求所有回答使用同一种推动方式。原话未表达的具体顾虑不应视为确定事实。

生成2至5个不同的有效候选角度，不为凑数量追加无关方向，按本次问题的相关性和用途从高到低排序。直接答案必须优先；有条件的后续推进任务须记录适用条件。候选角度既应能服务观众目的，也应在合适时支持直播内容策略。主动判断是否有适合本次问题的后续推进任务，说明采用或省略的原因。

一个角度对应一个主要讲述任务，使程序可以独立采用或省略。必答任务由观众原话决定；仅因资料里存在某项信息，不能把它并入必答。解释、场景和工艺等额外方向分别保留为候选。后续推进应优先帮助用户完成紧接着的有效行动或判断，而不是反复堆叠资料。对于简单明确的询问，建议采用角度上限为2：一个直接答案和最多一个当前最有用的后续任务；其他角度留待需要时使用。复杂问题可建议上限3并说明必要性。建议上限限制的是本次实际选用量，候选池仍保留不同角度。

允许根据事实进行自然的生活联想、主观感受和适当外延，按含义重新组织内容。商品数值、具体属性、优惠、交易和履约条件依据输入；事实记录中的禁止表达与纠正口径只控制选择和表达。事实引用仅使用输入提供的真实引用ID；引用不到的业务条件不能自行补齐。模拟夹具按本次测试输入处理，不能推成其他真实场次的业务事实。

采用条件使用输入“现场条件”中的字段与确定值，输出原字段名和比较值。比较值须与对应字段类型一致：字符串字段比较具体字符串，布尔字段比较布尔值；null代表未知，不能据此判定可采用。没有额外条件用空数组；存在未知条件不能判定为本次可采用。一个角度即使排在前面，也须通过条件判断才能选用。后续推进任务与对应角度的本次采用判断保持一致。建议正文长短由当前目的、必答内容和采用任务共同决定，不使用随机分配。

只输出JSON对象，字段均使用中文名称，结构为：

{
  "规范化问法": "字符串",
  "用户目的": "忠于原话的主要目的",
  "待确认顾虑": ["尚未确定的额外条件或顾虑"],
  "必答任务": "明确需要说清楚什么",
  "后续推进任务": [{"名称": "中文名称", "本次采用": true, "理由": "字符串"}],
  "角度": [
    {
      "优先级": 1,
      "名称": "中文名称",
      "讲述任务": "这个角度实际要帮助观众完成什么",
      "任务角色": "必答或可选推进",
      "事实引用": ["输入事实或福利的ID"],
      "采用条件": [{"字段": "输入现场条件中的字段名", "等于": true}],
      "本次采用": true,
      "理由": "优先级、适用条件和本次采用理由"
    }
  ],
  "建议采用角度上限": 2,
  "建议正文长度": {"下限字数": 20, "上限字数": 80, "理由": "按当前任务说明"}
}

优先级为从1开始的连续整数，本次采用为布尔值。不要生成口播，不要输出标题或JSON以外的文字。
