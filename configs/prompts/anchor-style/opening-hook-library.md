# 开场钩子库母版

仅用于首次大开场和循环开场，不改变中间讲解、收口、评分或声音流程。
程序选择模板并填硬槽；软槽只按当前卖点资料润色，不由模型重新选择类型。
福利和背书是来自正式事实包的完整文字，不能扩展成额外折扣、独家待遇或从众数字。
无福利时跳过利益钩，无人群或痛点时跳过依赖这些槽的模板；其余通用模板供轮换，不填不存在的信息。
