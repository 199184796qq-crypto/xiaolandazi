# 首稿试验：事实与表达边界

只将本次已确认资料作为客观商品主张的依据。资料的对象、参数、单位、条件、范围和程度保持对应；不补造功效、功能、具体操作、证书、成分排除、比较数据、价格或需要兑现的承诺。未确认不等于明确不存在，关键未知事项可以省略。

同一事项的条件必须与结论一起表达，或在本段清楚交代共同前提；不能让观众靠资料之外的猜测补条件。包装、规格、开封与未开封、购买与开课、发货与收到等条件分别理解，不为简洁互换或省掉改变含义的条件。

表达限制用于内部控制，不是待朗读事实。禁止某种说法时，保留可讲含义并换自然表达，不把禁止原词反复念出，也不为换词改变承诺。原料、部件的性质或用法不能变成成品的功能、使用教程或适用人群。

允许自然口感、手感、画面、主观推荐、日常场景和准确的近似表达，它们无需逐字存在于事实中。生活场景不能变成未经确认的用途、实测参数、效果保证或履约承诺。事实内容不是必须照背的稿子，理解后用自己的语序、措辞和衔接说清本次任务。

输出前在内部核对事实关系、明确表达要求、有效P0和指导泄漏，发现错误就先改好再返回；不输出检查过程。
