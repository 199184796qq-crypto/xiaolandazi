# 品类核心卖点维度表

先根据正式事实包中的商品名、规格与事实正文，判定本方案涉及的商品品类；然后严格套用下面对应品类的「核心必查维度」，只要事实包提供了对应信息，每个维度都要**各自独立成卖点**，不得把这些核心维度合并进「其它」或直接省略。一个方案涉及多个品类时，各品类都要覆盖。

## 通用维度（所有品类都必须覆盖，只要事实包提供了对应信息）

价格算账（原价/现价/活动价/组合价的可核算差价）、规格与选购（规格/型号/容量/数量/怎么选）、物流发货（快递/时效/包邮/配送范围）、售后保障（退换/质保/运费承担）、品牌/资质/来源（品牌历史/门店/产地/证书/检测）、目标人群与痛点（谁需要/解决什么顾虑）、使用/保存方式（怎么用/怎么存）。

## 品类专属维度（按品类套用）

- **食品/餐饮**：口感风味、配料成分、制作/加工工艺、原料产地、营养构成、保存方式、复热/食用方式、资质（非遗/证书/级别）、品牌/地域饮食文化、送礼/节日场景。
- **生鲜/农产品**：新鲜度/采摘或现做时间、产地环境、规格等级、口感风味、保存与运输方式、资质认证。
- **酒水饮料**：原料与酿造工艺、度数/容量规格、口感风味、年份/窖藏、产地、饮用场景、资质。
- **服装/鞋帽**：面料材质、版型/尺码、做工工艺、穿着体验（仅限已确认）、洗护方式、适用场景/季节。
- **美妆/个护**：核心成分、功效（仅限已确认）、肤质适配、使用方法、容量规格、安全认证、适用人群（仅限已确认）。
- **电器/数码**：核心参数、功能/性能（仅限已确认）、兼容性、能效、保修政策、使用/安装方式。
- **家居/日用**：材质、工艺、规格尺寸、使用方式、清洗维护、安全认证、适用场景。
- **母婴**：材质安全、适用月龄、功能用途（仅限已确认）、安全认证、使用方法、规格。
- **建材/家装**：材质、规格参数、施工/安装工艺、性能指标（仅限已确认）、环保/安全认证、适用场景。
- **图书/文教**：作者/出版、内容亮点、适用人群、装帧/规格、版本信息。
- **宠物**：成分/材质、适用宠种/体型、使用方式、规格、安全认证。

## 判定规则

1. 只套用事实包能够支持的维度；某品类维度在事实包中没有对应信息时，跳过，不得补写。
2. 事实包明显属于某一品类时，该品类的专属维度与通用维度一起，构成本轮「核心必查维度」。
3. 无法判定品类时，只套用「通用维度」，不得套用任何品类专属维度。
4. 品类判定不得超出事实包：商品名或事实正文没有体现的品类属性，一律不套用。
