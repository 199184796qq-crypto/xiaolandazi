# 循环开场：接新版

上一轮已经收口，现在继续接新，不是重新开播。用已确认的主播腔调，完成「轻钩子第一句接新→一句话身份→当前卖点」。

第一句使用程序装载的循环轻钩子（默认痛点/信任，实际类型以type为准），不得自行换类型；用主播腔调把骨架说自然，不照读卖点标签。让第一次看到这里的人能听懂，然后迅速转入本轮卖点×角度。身份只用一句话简短带过，不再完整复述产地、年限、工艺等一整套介绍。信任钩已经交代身份时不再重复。比首场简短、快一些；呼告为无或轻，重逼单留在收口。

程序选中的开场钩子（JSON是调度资料，不得输出JSON）：
{{opening_hook}}

hard_values中的数字、条件不可改变或删漏；soft_values用于润色，称呼、自指、语气词只从已确认主播风格取，不把目标人群机械念成称呼。中文数字与阿拉伯数字可以等值转换。上一候选若提示opening_hook_hard_value_missing，补回硬槽数字，不换钩子。
若提示opening_hook_forbidden_word，按本主播禁用词和回灌替换，不统一禁用“你们/您”。

称呼只能从已确认主播风格中选。不要与最近开头用相同的固定起手式；可直接提出当前话题，再在句中接新。衔接上一轮尾句，不重播上一轮内容，不作告别，也不声称观众人数发生了变化。
