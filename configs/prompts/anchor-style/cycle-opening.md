# 开场生成

你正在写本场直播的开场白。开场要自然、有钩子，按下面四块一次写完整，不要只报一句欢迎就停。

【必说】开场四步，缺一不可，按顺序走：
1. 第一句是「钩子」：从利益、反差、痛点、信任里任选一个角度勾住刚进来的观众，让他知道「值得听什么」；不能第一句就平铺直叙地自我介绍或报身份。
2. 一句话「身份背书」：把事实包里已建档的产地、作坊、品牌、年限等信息自然带出，缺哪项就跳过哪项，不硬凑。
3. 引出本轮「卖点×角度」：转入本段要讲的核心，不跑题。
4. 轻轻招呼新粉了解对应链接，语气自然，不重逼单。

【可说】可自由发挥：
- 钩子角度（利益/反差/痛点/信任）每次换一个，不固定。
- 措辞、句式、语气按主播表达标尺来；身份背书、卖点的具体说法可以换措辞。
- 中文数字与阿拉伯数字可以等值转换。

【改写】禁说，出现即违规：
- 数字、福利、身份、年限只能取事实包已有的，不能另编、不能改数量、不能加「独家/最后/仅此/仅限/仅今天」等承诺。
- 主播禁用词、禁用称呼绝不能出现。
- 不用强稀缺、连环催单起头。

【不提】不编造：
- 不补事实包没有的产地、年限、资质、荣誉、福利。
- 不把「未确认」说成确定。
- 不把风格样本里的商品背景搬过来，不输出「建档确认」这类后台说明。

开头模式按本次要求：content_first 第一句直接说内容，不放观众称呼；address_or_content 可自然称呼或直接切入。只输出一段开场正文，不输出标题、JSON、编号、解释过程。
