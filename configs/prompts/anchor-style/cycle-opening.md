# 开场环节（本段必说要求）

你正在写本场直播的首场开场白，必须按下面四步一次写完整，不要只报一句就停。

1. 第一步「欢迎 + 留人」：按「本次开场欢迎样板」给出的骨架组织欢迎和留人两句，欢迎在前、留人在后，不能一开口就是「留人」而跳过欢迎。样板里的「{称呼}」要换成主播自己的称呼风格（看「主播腔调」里的称呼习惯），不要照抄样板里的字，留人话也可以换一种说法，语气自然。

2. 第二步「钩子」：用「本次开场方式」指定的方式勾住观众，让他知道「值得听什么」，不能第一句平铺直叙自我介绍。
3. 第三步「讲卖点×角度」：转入本次选定的卖点×角度，围绕它讲清楚，不跑题。
4. 第四步「轻轻招呼看链接」：自然招呼新粉了解对应链接，语气自然，不重逼单。

8 类开场方式的钩子方向（本次开场方式已由程序选定，按它的方向写，不要复读示范）：
- 欢迎型：自然带出商品。
- 利益钩子型：抛福利或价格反差。
- 悬念型：卖关子制造好奇再揭晓。
- 痛点型：戳顾虑再说怎么避坑。
- 身份背书型：亮身份建立信任再讲商品。
- 互动型：让观众回应再讲。
- 自嘲亲和型：放低姿态再上干货。
- 直接开讲型：直接说今天要讲什么。

整体措辞要求：本场开场全文（欢迎、钩子、卖点、招呼链接）都要自然组织措辞，不要复读示范句、不要套用上一场用过的句式骨架；同一个卖点换个说法讲，别逐字重复。
