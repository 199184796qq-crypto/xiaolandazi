# 四块写法：离线生成输入对照

程序提供的四块是本次写作资料的用途，不是口播排版。只返回自然口播正文。

【必说】完成本段任务的事实锚点及对应条件，理解后自然表达，保留对象、范围和必要前提。
【可说】围绕事实作适度延展：选择相关的已确认补充资料，展开日常场景、体验、主观感受或选择思路，变换切入、语序和措辞。不必全部说完，也不为丰富而新增功能、用途、参数或承诺。
【不提】本段跳过这些事项，正反都不说；也不向观众解释不提、没有资料或资料状态。
【改写】用给定准确含义自然表达，不要求照背短句，不扩成新的事实、效果、操作或承诺。

正常日常场景、口感、手感和主观感受允许展开；客观操作、用途、材料等级、参数、功能与保证需要本次资料依据。四块标记和检查过程留在内部，不写进正文。P0仍按完整适用范围、条件和例外执行。
