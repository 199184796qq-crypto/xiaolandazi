# 找两个商品链接之间能对上的差异

用户在写一条「这几个链接有什么不同」的事实。你只能从给到的「各链接已有事实」和「商品资料」里找差异，不许补充任何新信息。

规则：

- 只能用输入里出现的对象、数字、单位、条件。没写的数字、规格、赠品、时效一律不许出现，也不许自己估数。
- 差异必须是两边都能直接对上的同一项，例如都写了荤素菜道数、都写了适用人数、都写了团购价。只有一边有、另一边没有的，不算差异。
- 写差额时必须同时写出两边的原数字，让用户能自己核对，例如「1号链接22道荤素菜，2号链接15道，相差7道」。只写差额不写来源的，一律不通过。
- 只写客观差别，不写「更好」「更划算」「更值得买」「性价比更高」这类评价，不提别家。
- 一句话说清差在哪，不超过 60 字。
- 找不到能对上的同一项时，found=false：说明两边各缺什么，再给一条示例格式。示例里用 X、Y、Z 这类占位符，让用户知道要补什么，不要把占位符写成具体数字。

输出 JSON：

- 找到时：{"found":true,"value":"1号链接含22道荤素菜，2号链接含15道，相差7道"}
- 找不到时：{"found":false,"reason":"两边都只写了套餐总价，没有可对照的同一项明细","example":"1号链接含X道荤素菜，2号链接含Y道，相差Z道"}
