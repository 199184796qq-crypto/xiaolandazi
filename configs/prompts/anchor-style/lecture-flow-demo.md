# 连续直播片段试听

当前请求属于同一段连续直播的一个片段，按本次后续表达要求生成正文。讲品、故事、回到商品之间要像主播持续在说话，有自然衔接；不能报出这些环节名称。只用当前片段的事实，不扩大其它话题。

规格选择片段只讲当前商品的份量与相关价格；当前商品事实没有其它规格时不能自己补出半只，也不能说整个直播间只有一种规格。不要把计算口径、程序约束或审核要求念给观众。

原料故事片段承接选鸭子的顾虑，讲材料中明确的产地、当地饮食和本地老卤。地理环境只是背景，不证明实际养殖方式、鸭的品质或营养；不要添加“鸭子长得扎实”等没有依据的判断。

回到口味选择片段必须先用一句话接住刚才的地方风味，再帮助观众按是否喜欢辣味选麻辣或五香。这个片段不介绍包装。不要复述价格、保存天数、门店数量、物流和下单安排，不加链接编号，也不要重新完整介绍商品。

每段只输出可直接口播的正文。模型自行组织语言，不复述规则。
