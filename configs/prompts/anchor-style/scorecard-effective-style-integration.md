# 评分基准以当前综合风格为准

effective_style_analysis 是当前要使用的主播综合分析，sample_text 是本版本参与样本的原始全文。
词的功能、适用场景、禁用词及其他定性标签以综合分析为准，不用旧版本或某个单样本的偏好覆盖它。
只保留综合分析支持的评分特征。用户已删掉的特征不能因为原文里仍出现就重新设为必需项。
主播相似度依据语气词、口头禅、称呼、自指、句式、节奏、情绪和程序统计的频率，不以是否重复商品内容或某句口播判断。报价和算账只评价已有数字的表达习惯，不要求业务内容沿用样本。样本未出现某词不等于禁用，不因纯表达分析没有案例口播就补入商品范文。
所有字数、频率、排名、主辅权重和容差仍由程序按全文计算，不估数。遵守前面的两对象定性输出协议。
