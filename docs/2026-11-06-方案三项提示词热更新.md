# 三项方案提示词保存热更新

用户确认直播话术要求、互动回答要求、话术规划可在直播中点击顶部“保存方案”热更新；并确认保持原用途，不把直播话术要求额外拼入自动主线改写。

直播中的方案提示词页保存走独立三字段接口：直播话术要求只更新其保存原文与编译结果；互动回答要求用于后续互动模型正文，话术规划用于后续自动主线改写。保存期间锁定编辑与重复提交，失败/冲突保留草稿。后台按租户、方案、现有写权限限制，使用方案行锁、提示词行锁、内容revision校验，三项原文与对应编译结果单事务落库，无新表/列迁移。

人设、事实、红线、编辑来源元数据、方案版本、声音和原稿不通过该接口改动；这些页面的未保存草稿仍保留，并明确提示停播后保存。停播后的保存沿原完整版本与六页保存流程。旧完整方案保存守卫继续生效，只有方案提示词页显式请求热更新能力。

互动读取保持当前场次/版本、声线、P0和已准备正文的身份。后续新模型请求读取已确认热更新的互动要求；已生成正文继续使用固定快照，临时提示词读取失败也不取消已准备任务或触发重买。主线改写只有在当前人设/事实/红线与开场冻结模板严格匹配时采用新规划；原付费库存、生成机会节奏、排队与实际播放不被清理或重置。有兼容库存可继续使用，并非保存就强制购买新声音。
