## Docker 修复记录

原 Docker Desktop 本地 WSL 数据环境异常，表现为 Engine 长时间停留在 Starting。
处理方式：

1. 强制退出 Docker Desktop 与后端进程
2. 执行 WSL shutdown
3. 注销旧 docker-desktop WSL 发行版
4. 将旧 Docker Local/Roaming 数据目录改名备份
5. 重新启动 Docker Desktop，让其重建全新环境

旧目录未直接删除，保留为 broken 时间戳备份，便于需要时回查。
