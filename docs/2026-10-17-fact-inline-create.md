# 表格底部添加事实依据

## 行为

“添加事实依据”由页面上方移至已采纳事实表格下方，随表格增减行自然移动。点击后表格末尾增加一条输入行并聚焦事实内容，无弹窗。一次录入一条；输入完成离开该行或点击行内保存即提交，取消或空行不写入。中文组合输入结束前不提交，保存期间锁定草稿，失败仍可修改或重试。

新行保存前显示“保存后选择归属”，不把未归属事实标成公共。保存成功后恢复原归属下拉框。已有事实的修改自动保存、归属范围排序、显示序号、隔行颜色、四层展开及三个操作按钮保持。

## 原业务链路

仍使用useFactNameSuggestion和POST /api/v1/live-agent-plans/{planId}/fact-name-suggestion提炼名称；名称提炼失败时可在同一单元格手动填写名称。

仍通过adoptLiveAgentPlanFacts调用POST /api/v1/live-agent-plans/{planId}/facts/adopt，tenant_id、source_ref=manual:fact-editor、分类、提炼名称、事实正文及原候选字段维持原协议。禁说/改写由原normalizeFactForSave及审核模型整理，而非前端伪造；后端的审核、审计、去重、冲突和热同步逻辑均未修改。

前端检查adopted/unchanged结果及saved/existing的方案、租户和ID后才关闭草稿并显示服务端完整结果；blocked/conflict/空回执保留草稿。失焦与按钮提交共用保存锁，避免重复请求。使用当前范围序号隔离A→B→A迟到回执，旧保存不能清除新方案的保存状态。只改变前端入口及反馈处理，无新增后台接口或数据库写入方式。
