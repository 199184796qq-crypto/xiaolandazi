# 商品资料补充界面

按用户提供的第二张参考图调整现有商品资料补充面板。使用已整合的 main 源码，保留商品资料、活动福利、资料补充、事实依据、任务讲解入口及原有待确认、保存、取消和方案隔离流程。

- 左侧渐变资料卡、文档插画、分类提示和补充引导；有待确认资料时继续按分类显示真实候选与确认保存按钮。
- 右侧资料助手头像、对话气泡、提示装饰及独立返回补全清单入口。继续使用已有真实聊天接口，不改模型、提示词、事实整理或保存协议。
- 输入框与上传文件、快速示例、回车发送及发送按钮合为一个面板。
- 上传文件支持 TXT/Markdown（UTF-8或GB18030），最多1MiB且合并输入不超过3000字。文字先填入输入框，用户确认后发送；读取失败不替换原输入，切换方案或账号后旧读取失效。不会直接保存文件内容为事实。
- 快速示例提供原料工艺、配送保存、品牌产地三个补充话题，只预填输入、不自动发送或保存。
- 回车偏好沿用原来按用户保存的设置；其它页面仍显示原“回车”标签。
- 窄屏上下排列，工具栏换行，长对话和待确认资料可滚动。

前端类型检查及生产构建通过，原资料补充、方案导航和初始化操作共13项回归通过。使用本地合成方案验证文件读入、示例预填、回车发送、分类展示及用户确认保存；390像素窄屏无横向溢出。未修改真实客户资料或调用付费模型。

发布仅添加桌面/兼容入口的新哈希资源并替换两个入口HTML。继承发布前实际current全部其它文件，保留旧哈希资源、手机端、后端二进制、提示词及Nginx路由；不重启服务。上线版本和实际文件核对记录在聊天工作区 `work/supplement-ui-proof`，最新前端备份由 `work/frontend-preservation/latest.json` 指向。
