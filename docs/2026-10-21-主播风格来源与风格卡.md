## 功能

主播增加“风格来源”二选一：

- **风格卡**：手动设定的人设、称呼、口头禅、节奏、强度、地域等
- **风格样本**：导入真实话术 → 分析结果 → 旧链路

左侧主播卡新增“风格”下拉框：

```text
风格：[风格卡] [风格样本]
```

选择后：

- 风格卡：只显示“主播风格”页 + 个性化挂载
- 风格样本：显示“风格样本” + “风格分析结果” + 个性化挂载
- 已有样本的主播仍可切换到风格卡；两套 profile 分开保存，不互相覆盖

## 数据与后端

`live_anchor_styles` 新增：

```text
style_source_mode VARCHAR(16) NOT NULL DEFAULT 'sample'
style_card_json   MEDIUMTEXT NULL
```

- `sample`：沿用 `profile_json`（样本分析/旧链路）
- `card`：使用 `style_card_json`
- `GetLiveAnchorStyle` 按来源返回生效 `profile`，绑定和生成链路读取生效 profile
- `UpdateLiveAnchorStyle` 支持 `style_source_mode` 与 `style_card`，风格卡不再受样本分析版本锁限制

## 默认值

- 新建主播默认“风格卡”
- 默认人设：自然、口语、像在跟一个人说话
- 默认称呼：朋友们、老乡们
- 默认避免词：家人们、宝子、亲爱的
- 默认补充：不主动推荐链接；事实没有的不补、不猜

新建时直接写入默认卡，不需要用户先填一堆空字段。
