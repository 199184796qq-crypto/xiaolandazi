# 终端智能体：只保留聊天界面（2026-09-24）

## 用户确认的界面范围

终端客户不需要统一“我的待办”。结合标注截图，终端智能体保留可配置的智能体名称、关闭按钮、真实对话、思考提示、输入框和发送按钮。删除工作域/用户层上下文说明、顶部技术标签、常驻能力标签、“对话/我的待办”切换、重复的上下文空态卡片。初始内部系统介绍不展示给终端客户；没有消息时不填入新的功能或统计卡片。

桌面终端和 customer-mobile 同步简化。主要标题、聊天正文及输入使用 18px。桌面抽屉为标题/可滚动对话/底部输入三行布局，不保留删除内容的空白轨道。内部员工、财务、运维、销售（含 sales-mobile）的分类待办保持。

## 英文副标题与发送按钮（2026-09-24 补充）

终端中文智能体名称下方增加 `XIAOLAN LIVE COMPANION`，14px、独立一行、与中文左对齐；不恢复工作域说明、能力标签或待办。中文名称仍沿用系统设定。桌面终端及客户手机端同步。

发送按钮保持18px文字，48px高度、12px圆角矩形，与输入框垂直居中；空输入、可发送、悬停、键盘焦点及窄屏均保持对齐。输入框改为块级布局，消除文字基线对居中的干扰。内部员工和销售界面不受终端样式影响。

专项浏览器模拟回归新增英文副标题位置、四角圆角与按钮/输入框中心检测；桌面及手机端测得中心差为0px。沿用原聊天、思考提示、直播间上下文及终端无待办测试。

## 边界

展示简化不删除直播策略能力或变更权限。当前直播间、策略/主播训练/固定话术/声音/基础设置上下文仍按已有路由和事件处理。关闭常驻能力展示，不删除用户主动输入命令的既有能力。

终端待办导航、角标、意图面板、自动快照与推送通过统一角色规则禁用，customer-mobile 不再挂载待办组件。旧桌面待办地址不向客户打开。收款资料、订单进度、申请运维和确认处理结果仍在原业务页办理；不清空、完成或修改任何真实业务记录。

## 本轮验证

`scripts/test-terminal-agent-ui.cjs` 使用独立 Chrome 用户目录，所有 API 和 EventSource 均为模拟。覆盖：桌面终端无工作域说明/能力标签/待办或重复卡片、三行布局与 18px、实际聊天与思考提示、终端零待办请求和连接、旧地址拦截、员工及销售待办保留、customer-mobile 直接聊天。

策略回归在测试浏览器内用精简宿主页挂到现有策略路由名称，运行真实 SystemAgentLayer，并检查请求携带选中直播间 701；不替代生产策略业务表单或真实大模型调用验收。

桌面和客户手机端类型检查及构建通过。UI 测试中的前两次失败为测试脚本问题：输入后未等待响应式按钮更新、测试导入了另一份路由实例；修正为等待 DOM 更新、使用当前应用路由后重跑通过。未因此改写真实业务。
