# 六页提示词多模板管理与选择

后台“提示词维护”按主播人设、事实依据、红线禁止、直播话术要求、互动回答要求、话术规划分别保存多份命名模板，可新增、改名、编辑原文、删除。每标签最多20份，每份名称最多60字，正文最多20000字和60000字节；沿既有TEXT列，每标签JSON序列化合计最多60000字节（含格式），前后端一致校验并在页面提示。保存全部目录为单事务及版本比较，冲突/失败保留草稿。

方案页移除“拉取提示词”，六个标签后增加“模板选择”。弹窗只读加载当前标签模板，选中预览，明确确认后仅替换当前页草稿；统一顶部保存方案采用。取消、读取失败、过长、迟到回执、切方案/页/保存不会覆盖新稿。人设替换清旧来源元数据，同内容替换也重置删除/新增草稿；结构化/单文本框双显示、删除角标、内联新增继续使用。

模板原文直接复制，包括空白、占位符及空内容；不会调用模型或自动按商品资料填充。新目录初始六页为空，需要后台添加，旧模型生成母版不是正文模板，不自动迁入。旧生成接口和六份生成指令存储继续兼容，维护目录不会覆盖已有客户方案或运行快照，也不增加模型输入。

API：运维 GET/PUT `/api/v1/system/plan-prompt-template-catalog`，沿用 `system.settings.liveops.manage` 权限；客户 GET `/api/v1/live-agent-plans/{planID}/prompt/templates?page=...`，沿用方案租户/访问校验，只返回指定页。目录使用既有系统设置表六行JSON，无迁移；通用设置隐藏并拒绝旁路写入；GET不写默认值。生产不代用户创建模板或保存方案。

实现/验证与发布证据分别在 `E:/直播伴播-local/prompt-template-catalog-20261105`、`E:/直播伴播-local/prompt-template-catalog-release-20261105`。

验证：Management全量3736项通过、141条件跳过、71个测试包通过；隔离MySQL另实跑目录保存/删除/精确原文/并发首存/失败回滚/损坏拒绝，测试schema清理且端口关闭。23项解析/编译，结构化26组、双模式12组、删除模式10组、父页保存6组及多模板专项15组，合计69组浏览器回归通过，零浏览器错误/外部业务请求。类型、生产构建、vet及10项发布空闲守卫通过。实际线上Management和前端均独立重建完整SHA匹配，完整4486项旧前端备份核验一致。浏览器数据为本机模拟，不是生产客户写入测试。
