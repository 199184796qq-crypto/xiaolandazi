# 方案声音语速自动保存与回显

用户要求每个直播方案增加声音语速、默认1；直播页修改后自动保存，退出重进真实恢复，并覆盖新建和以后创建的所有方案。本轮基线 `6b6f349`，唯一主目录 `E:\直播伴播`，尚未部署。

## 最终行为

- 方案配置页“声音”上方增加“声音语速”，选项0.8、0.9、1.0、1.1、1.2，修改即保存。直播页原语速控件读写相同的方案设置。
- 设置按租户+方案保存。同一方案绑定多个房间时共用语速；其他方案、其他客户独立。所有方案走统一接口，没有写死客户/方案编号。
- 新建且没有版本的方案读取为1，首次保存版本也从服务端保证为1，不继承前一个方案或房间音色的语速。已有方案尚未设置新字段时，兼容最近有效保存版本的语速，缺失或无效为1。之后显式保存的方案设置优先。
- 修改后不需要再点击“保存方案”。退出重进、切换后返回均从服务器读取；修改音色或恢复旧工作区不会覆盖此设置。设置用于下次开播及以后新生成的声音，已经排队/播放的声音和用户上传原始录音不做即时变速。
- 保存中禁用重复操作；失败回退到实际已保存值并显示原因。读取失败禁用选择并可重试，不把读取失败当作默认值保存。按账号/租户/方案/房间上下文隔离迟到响应，A→B→A亦重新核对服务器真值。

## 后端与兼容

- `live_agent_plans.voice_rate DECIMAL(3,2) NULL DEFAULT NULL`。启动迁移只在缺列时添加，重复启动不重置已存设置；NULL保留旧方案向原版本回退的能力。
- 新接口 `GET/PUT /api/v1/live-agent-plans/{planID}/voice-rate?tenant_id=...`，写入体仅为 `{"rate":1.1}`。沿用现有登录、租户、方案和L3授权校验，拒绝无效值及其他租户/已删除方案。
- 新版本保存持有方案行锁并使用服务器当前语速，防止旧页面提交的voice_identity.rate覆盖设置。运行方案投影读取当前设置；按编号读取历史版本仍保留原始记录，不修改历史快照。
- 旧的房间 `published-version/voice-rate` 接口兼容为写同一份方案设置并返回相同形状的版本投影，不为一次语速选择创建完整版本或调用派生安全/模型流程。
- 本轮未改 `web-console/src/api.ts`；独立模块 `planVoiceRate.ts` 使用原request封装，保留WorkBuddy正在修改的事实预览API。
- 收尾发现WorkBuddy在共享 `httpapi/server.go` 中同时删除semantic-review路由；本轮只行级提交语速GET/PUT两行，其余删除及对应业务源码保留给WorkBuddy，交接已登记，不覆盖或代提交。
