# 问题1 修复：卖点×角度与侧面不匹配（已改，待提交）

## 现象

调度选「特色菜」角度，侧面却轮换到「利益算账」，把 flavor/craft/origin 主体事实全滤掉，最后话术只剩 price 去讲价格。

## 根因

侧面选择与事实完全解耦：

- `CurrentFissionSide()`（`angle_plan.go`）只按 `s.Used[task.Key].Count` 轮换计数 + `SideUses` 历史选侧面，**从不读当前任务事实**。
- `HookFactsForSide()`（`fission_side.go`）按当前侧面筛事实，把不匹配侧面的主体事实滤掉。
- 两条链路独立，轮换到事实撑不起的侧面时，主体事实被滤光、只残留 price。

## 改动（2 个文件，未提交）

### 1. `internal/anchorcycle/fission_side.go` — 新增 `SideHasDedicatedFact`

```go
func (s *State) SideHasDedicatedFact(side string) bool
```

判断某侧面在当前任务事实里是否有「专属事实」支撑：
- 专属事实 = category 能映射到该侧面，且 category 非通用（不在 `FactSideMap`/`factCategorySides` 表里或为空，都不算专属）。
- 通用事实（other/未知）任何侧面都能引用，**不能**作为「某侧面有支撑」的依据（否则退化回「所有侧面都有支撑」）。

### 2. `internal/anchorcycle/angle_plan.go` — 改 `CurrentFissionSide`

在原有轮换逻辑之前，先筛「有专属事实支撑」的侧面子集：

```go
supported := 有 SideHasDedicatedFact(side) 为 true 的侧面
if len(supported) == 0 {
    return ""   // 无任何侧面有专属支撑 → 返回空，HookFactsForSide 回退全量
}
pool = supported
// 原有轮换逻辑不变，在 supported 内轮换
```

## 兜底语义（关键，务必对齐）

- **侧面筛不出支撑 → 返回 `""`** → `HookFactsForSide` 走 `side == ""` 分支回退全量事实，让模型拿到完整素材自己组织，**绝不硬套一个侧面把事实筛没**。
- `HookFactsForSide` 原有的 `len(out)==0` 兜底**未改**：既然 `CurrentFissionSide` 已保证选出的侧面必有专属事实，筛出结果一定非空，无需额外放宽。
