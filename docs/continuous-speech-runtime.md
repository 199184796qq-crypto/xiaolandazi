# 持续口播生成运行时

## 1. 目标与边界

持续口播不是一次生成一篇长稿，而是由时间推动、逐个生成小段，并在每个小段完成后更新内容游标。

本运行时只属于 Management 的生成前编排层：

- 不修改 Core 的打断时机、优先级、恢复位置、安全点或播放队列。
- 不接管互动策略。互动策略仍决定什么问题必须回答、少回答或不回答。
- 不接管互动内容策略。互动内容仍根据当前问题和正式事实生成。
- 不把模拟房间参数作为真实直播事实播出。
- 最终声音版本、时间线和刷新仍通过现有接口交给 Core。

## 2. 核心循环

```text
虚拟时间推进
  -> 读取正式事实、有效福利、正式链接、主播风格、叠加能力
  -> 读取已经提交的小段、事实冷却、表达动作冷却和剩余字数
  -> 生成 Next Segment Spec
  -> 大模型只生成当前小段
  -> 硬边界审计
  -> 仅对失败小段补正
  -> 加入 pending
  -> 测试/离线生成确认后 commit
  -> 下一时间单元
```

线上真正的“已经讲过”应以 Core 实际播放结果为准。当前离线测试和预生成在小段通过审计后立即 commit；未来若接入实时动态小段，必须等播放确认后 commit，废弃的 pending 不得进入长期记忆。

## 3. Next Segment Spec

每次只向模型提供一个当前任务单：

- `speech_act`：当前讲话动作，例如直接讲事实、问后自答、回顾承接。
- `goal`：当前小段希望达到的听众效果。
- `fact_keys / benefit_keys / link_keys`：优先使用的正式内容锚点。
- `expression_move`：本段优先采用的表达动作。
- `style_capabilities`：本段允许出现的偶发主播表现插件。
- `interaction_opportunity`：只允许提出无人回答也能自然继续的开放问题，不代表已经收到互动。
- `previous_tail`：上一小段的短结尾，只用于自然衔接。
- `avoid_recent`：冷却提醒，是软约束，不禁止直播需要的重要事实回环。
- `target/min/max_chars`：当前小段字数调节目标。
- `remaining_chars`：整轮实际剩余预算。
- `constraint_level`：`soft`、`tight` 或 `closing`。
- `finish_mode`：继续、准备收束或结束当前轮次。

## 4. 长度债务

- 前段使用软范围，优先自然完整。
- 实际偏短或偏长会自动进入剩余预算，由后续时间单元分摊。
- 最后两个单元逐步收紧。
- 最后一个单元按剩余预算生成。
- 当前小段过长时只退回当前小段缩写，不重写整篇。
- 总文案只允许小范围最终误差。

## 5. 软硬约束

### 硬约束

- 法律、平台及 L1/L2 绝对规则。
- 用户明确锁定的价格、规格、链接、活动权益、产地和履约事实。
- 未授权的具体商业数字、库存、销量、评价、资质和真实人物证言。
- 将内部模拟在线数、进房量或评论量冒充真实状态。
- 将“换个说法、重复一遍、品牌背书、收一下”等编稿动作直接念给观众。

硬约束失败时，当前小段必须补正或拒绝。

### 软约束

- 主播风格执行度。
- 口头禅与称呼的出现密度。
- 单个早期小段的字数。
- 事实覆盖率。
- 与较早内容的语义相似度。
- 表达插件的建议次数。

软约束用于评分、冷却和后续调整，不能让整篇文案直接消失。Qwen 同步质检只观察并报告，不擅自整篇重写。

## 6. 事实重复与内容扩展

系统限制的是“同一事实 + 同一角度 + 同一表达动作 + 紧邻位置”的机械重复，不禁止重要事实在不同时间合理回环。

内容扩展遵循用户选择的 `fact_expansion`：除法律、平台、L1/L2 绝对禁区和 `always_locked` 外，可按授权级别使用场景、类比、故事框架、常识推演、情绪和促单表达。审核边缘优先换成合规说法，而不是整段沉默。

## 7. 三种主线模式

### AI 固定声音

按时间单元生成多套连续小段，合成为现有正式声音版本。Core 继续按现有轨道选择、预取和安全点播放。

### 原始真人录音

不改写原始录音。仍由现有 Core 播放与恢复机制负责。

### 本场预生成并低频更新

初始版本按时间单元生成。约两小时一次的局部更新只选择既有时间线窗口，将该窗口再按小段生成并重新合成；未选中的 PCM 保持不变，仍通过现有原子刷新协议在轨道边界切换。

## 8. 验证要求

- 100、500、1000、2000、3000 字目标均按多个小段生成。
- 当前小段过长会收到只缩短该段的补正请求。
- 风格偏差返回正文和评分，不触发整篇重写。
- 硬事实错误不能进入结果。
- 有限事实的四小时模拟应保持时间单元连续、预算可收束并产生事实/表达冷却信号。
- Management 全量测试与 Web 构建通过。
- Core 不修改，并执行 Core 全量回归测试。
