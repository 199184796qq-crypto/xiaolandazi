# 话术规划与修改元提示词编辑

状态：本地实现完成，未提交、未部署。

“方案提示词”在“互动回答要求”后新增“话术规划”标签，使用同一个带字数统计的 20px 文本框。加载时读取本方案现有 `rewrite_prompt_md`；编辑的是三份方案元提示词中的话术修改元提示词，另外两份组合逻辑保持。

顶部“保存方案”和页面内“保存方案提示词”均提交五页原文及话术规划。顶部保存冻结本次草稿，正式版本失败不继续写入提示词；提示词保存失败保留草稿，并提示部分成功、允许重试。未打开提示词页直接保存会先读取已有规划；切换方案和刷新分别回显自己的内容，旧读取响应不能覆盖新方案。

后端沿用现有 `PUT /api/v1/live-agent-plans/{id}/prompt`，新增可选请求字段 `rewrite_prompt_md`。传入时验证最多 20000 个 Unicode 字符，在同一条 UPSERT 中保存五页原文、互动组合、主线组合和修改元提示词，禁止随后再用母版覆盖手工内容。原始空白、换行、提示行和 `{{样本话术}}` 等占位符原样存储；样本正文仍由改写请求提供，保存时不注入样本。显式空字符串可保存；运行时为空仍沿用现有母版兜底。旧客户端未传此字段时维持原自动编译分支。

“重新生成”仅影响前五页，确认弹窗明确保留话术规划。未新增模型调用、额外规则层、重试或计费请求；未改变直播读取当前方案修改元提示词及开播冻结快照的业务入口。已有直播中方案禁止保存的保护保持。
