# Qwen3.8 聚类调用 Token 消耗问题（2026-10-28）

## 现象

房间 29（许府牛，方案 5，会话 517）12 分钟直播里，互动计费出现大量 qwen3.8-flash 调用：

| 项 | 数值 |
|---|---:|
| 调用次数 | 117 |
| 输入 token | 928,682 |
| 输出 token | 18,520 |
| 单次输入 | 约 7,900–9,700 token |
| 已结算 | 26,615 微元（0.0266 元） |
| 占本场模型费用 | 约 71% |

同期 deepseek-flash 只有 73 次、11.5 万输入 token、0.0066 元。模型费用整体的 71% 花在这一个调用上。

## 定位结论

用 qwen3.8-flash 的是**问题语义聚类**（stage `question_cluster`），不是互动话术生成。

调用链：

1. `management-service/cmd/...`（main.go:322）启动 `questioncluster` worker；
2. `questioncluster/worker.go:275` 以 `Stage: "question_cluster"` 发起模型请求；
3. 经 `httpapi/live_cost_adapter.go:615 CompleteLivePaidModel` 包装，计费原因统一写成「直播必要互动模型调用」（第 622 行），所以从 `live_cost_requests.reason` 看不出 stage；
4. 计费 key 形如 `question-cluster:{sessionID}:{externalID}:{maxEventID}:question_cluster`；
5. `question_cluster` 不在 `agentgateway.UsesInteractionAnswerModel` / `UsesInteractionPurposeModel` 的 pinned 名单里，因此走房间模型池，当前池里是 qwen3.8-flash。

提示词配置项：`question.cluster.system`（「问题语义聚类」）。

## 为什么贵

1. **prompt 太大**：每次把整批待聚类问题 + 事实/风格上下文一起送，单次约 9.7k token；
2. **调用太频繁**：每来一批弹幕就聚一次，12 分钟 117 次，折合每分钟约 10 次；
3. 单次输出很小（平均 158 token），成本几乎全在输入侧。

粗算：9,700 token × 117 次 ≈ 113 万 token/12 分钟，按 1 小时约 560 万输入 token。

## 连带问题：预估失真

同一批调用预估 200,594 微元、实结 26,615 微元，**虚高 7.5 倍**。原因是预估按模型配置档位全价计算，而实际回执按供应商折扣/缓存结算。

影响：预算面板显示花费远高于真实值，滚动小时预算被虚占，可选更新比例被压低——与「模型便宜就多更新」的目标相反。

## 修复建议（按优先级）

1. **聚类换模型**：把 `question_cluster` 加进 pinned 名单（或单独指定一个便宜的小模型），不要占用 qwen3.8-flash；
2. **压 prompt**：只送最近 N 条待聚类问题 + 紧凑事实摘要，目标单次 ≤ 2k token；
3. **降频/合批**：聚类按时间窗口或攒够 N 条再触发，避免每批都调；
4. **预估对齐实结**：模型预估改用与回执一致的 token 口径（cached input 单独计价），消除 7.5 倍虚高。

## 相邻问题（待查）

同一场里欢迎、直答、兜底这些已写进 `UsesInteractionAnswerModel` 的 stage，回执模型仍记为 qwen3.8-flash，说明 pinned 解析没有真正生效，落回了模型池。需要单独核实 `OperatorModelResolver` 的接线。

       COUNT(*), SUM(in_tok), SUM(charged_micros)
FROM (
  SELECT CAST(JSON_EXTRACT(request_json,'$.input_tokens') AS UNSIGNED) in_tok, charged_micros
  FROM live_cost_requests
  WHERE room_id=29 AND kind='model'
    AND JSON_UNQUOTE(JSON_EXTRACT(request_json,'$.model'))='qwen3.8-flash'
    AND requested_at >= '2026-10-28 03:35:00'
) t GROUP BY bucket;

-- 计费 key 确认聚类来源
SELECT JSON_UNQUOTE(JSON_EXTRACT(request_json,'$.key')), estimated_micros, charged_micros
FROM live_cost_requests
WHERE room_id=29 AND kind='model'
  AND JSON_UNQUOTE(JSON_EXTRACT(request_json,'$.model'))='qwen3.8-flash'
ORDER BY requested_at DESC LIMIT 5;
