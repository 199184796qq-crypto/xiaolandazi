# 资料导入重复属性对比与合并

界面只保留按对象、待处理、重复属性三个入口。待处理只列归属为空的资料；风险、待拆分和审核待确认仍有各自提示，不计入待处理。

重复属性显示红色数量与提醒。点击进入页面内对比区，每条显示草稿/库来源、适用对象、正文、标准值、条件、例外与可展开原文。用户选中一条后，可以保留该条的内容和归属，或者使用该条正文并合并本组适用对象。先展示结果与将移除数量，明确确认后执行，不弹出额外分配窗口。

重复候选按相同分类、属性键（或相同属性名称）、相同条件/例外检索，适用范围相交或正文/值一致时成组。独立链接价格不同不是重复；不同地区/金额条件独立保留。全局与链接范围重叠可以比较，全局合并仍为全局一条，商品卡界面继续不重复显示全局。待归属不自动推断对象，只有用户显式选择合并/保留时才采用预览范围。当前不增加语义判别模型，不能保证识别不同属性名称和键的同义事实。

草稿重复本地处理、保存到浏览器；追加同一属性不会静默吞掉候选。重复草稿不进入普通确认入库所选集合，其它独立草稿可正常入库。涉及库中资料时通过 POST material-claims/resolve-duplicates 一次处理，保留已有一条 ID，删除同组其它记录。请求明确列出库中源记录及各自 revision；读取时的 revision 由原始数据库行计算，不能使用经过归属投影后的数据生成。

服务端在付费向量前检查记录身份，事务内锁定租户/方案和资料后再次核对 revision，更新保留内容/向量与删除其余条目原子提交。未改变向量文档时保留原向量；变更正文或归属时只为保留的一条调用现有 Qwen 向量接口。向量失败、并发修改、删除失败全部保留原资料，不用顺序前端删除模拟原子性。库记录更新失败时草稿也保留。现有正式事实、运行版本、模型提示词及播放审核保持。

验证：实际 Vue 组件搭配父页/全局样式的浏览器模拟接口；独立临时 MySQL 验证回滚、租户隔离、过时比较、并发单胜、稳定 ID、多对象一行一向量及原向量保留。测试未调用真实模型、TTS 或写入生产商户资料；模拟接口不代表已做生产登录保存或直播实机验收。
