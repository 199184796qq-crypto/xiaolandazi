# 小智设备控制 Agent - 音量与字体控制方案

## 一、目标

小智设备收到用户语音后，优先识别设备控制指令。

当前第一阶段只支持：

1. 音量调整
2. 文字大小调整

不进入直播智能体业务链路，不消耗 AI 时长。

---

## 二、整体架构

```text
用户语音
↓
小智麦克风
↓
音频上传网关
↓
ASR识别
↓
设备控制意图识别
↓
Device Control Agent
↓
小智设备执行
```

---

## 三、控制指令

### 1. 音量控制

支持：

- 声音大一点
- 音量调高
- 声音小一点
- 降低音量
- 最大声音
- 静音

统一协议：

```json
{
  "type": "device_control",
  "action": "volume",
  "value": 70
}
```

调整方式：

- +10
- -10
- 0-100 固定值

### 2. 字体大小控制

支持：

- 字体大一点
- 放大文字
- 字太小
- 缩小文字
- 恢复默认字体

协议：

```json
{
  "type": "device_control",
  "action": "font_size",
  "value": 32
}
```

---

## 四、设备端执行

小智收到控制协议：

- `volume`：调用音频驱动调整播放音量
- `font_size`：调用 LVGL 字体配置切换

---

## 五、架构隔离

小智终端：

- 麦克风采集
- 控制指令执行
- 播放声音
- UI 显示

Core：

- 直播业务
- 智能体
- TTS
- 直播策略

设备控制不进入直播智能体。
