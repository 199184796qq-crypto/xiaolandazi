# 取消全部小时预算

状态：本地实现和验证完成，未提交、未部署。覆盖前轮尚未发布的“主线 1.3／3 元、互动无限额”方案。

## 行为

主线声音、话术改写、互动文字模型和互动声音均取消小时金额预算；原主线／可选／总目标以及标准池 1.3 元、高仿真池 3 元等金额不再限制生成。旧的每方案每小时 14000 汉字合成门槛和对应环境变量也不再生效。不是把限额换成一个很大的数。

原来因预算延后的生成按现有播放、片段及版本池规则恢复，实际模型／TTS调用量可能随之增加；没有增加新的模型步骤或重试。供应商速率、并发、模型输出长度、版本池及缓存复用规则保持。

## 记账与兼容

- 应用的默认费用控制器、有效价格设置和房间运行态均采用 `AccountingPolicy`；`AccountingOnly` 明确禁用小时金额准入，仅保留价格、身份、请求预留与结算。
- 不查询累计金额来批准新请求，不因历史未决或已花费用拦截主线／互动／改写。小时窗口仍可用于费用统计，不能再当作额度。
- 仍验证场次、方案、语音池与有效价格；价格、数据库或必要耐久记录不可用时的保护保持。这些是正确记账及业务身份错误，不能当作“额度不足”。
- 之前已拒绝且明确未发送的费用请求可以恢复；已发送、待结算或回执未知的同一请求仍有防重复购买保护。历史费用、旧预算文件、用户音频及缓存没有被清空或重写。
- 后台成本面板移除小时预算输入，只维护声音／模型参考单价。新客户端可不传旧预算字段；旧客户端及冻结价格快照仍可带这些字段，但字段值和顺序均不影响请求或有效价格。
- 原文及改写的后台规划不再根据剩余金额削减可执行的已到期片段；冷缓存首轮、可用库存、片段顺序、版本池与原重试边界保留。
- 通用内部旧策略／计算辅助保留用于历史读取与回归，应用运行入口固定采用仅记账策略，不从数据库旧金额字段重启预算。
