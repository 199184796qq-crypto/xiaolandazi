# 仓库目录与本地产物规范

## 目标

`E:\直播伴播` 只保存需要版本管理的内容：源码、配置模板、脚本、文档、任务说明和必要测试素材。

本机生成、可重建、含运行状态或仅用于发布/回滚的文件，不进入 Git，也不长期堆放在源码目录。

## 本地工作区

默认使用仓库同级目录：`E:\直播伴播-local`。

也可以通过环境变量 `XIAOLAN_LOCAL_ROOT` 指定其他位置。

- `backups/`：本地服务切换产生的可执行文件备份。
- `archive/`：历史候选二进制、旧部署包、一次性导出文件。
- 后续服务器发布产物也统一放到这个目录，不再写入 `data/exports`。

## 仓库内应保留

- `core-service/`、`management-service/`、`collector-worker/` 等业务源码。
- `web-console/`、`customer-mobile/`、`sales-mobile/` 等前端源码。
- `configs/*.env.example` 等不含密钥的配置模板。
- `scripts/` 自动化脚本。
- `docs/`、`系统设计/`、`tasks/` 项目设计和任务资料。
- 已明确需要版本管理的测试素材。

## 仓库内允许存在但禁止提交

这些目录是开发工具或现有运行链需要的工作路径，保留路径但由 `.gitignore` 隔离：

- `node_modules/`、`.svelte-kit/`、`dist/`。
- 各服务 `bin/` 中当前运行所需的本地可执行文件。
- `data/logs/`、`data/cache/`、`data/run/`、`data/recordings/`、浏览器 profile 等运行数据。
- 本机 `.env`、`*.local` 配置。

其中历史二进制和发布导出包应迁移到 `E:\直播伴播-local`，不要在 `bin/` 和 `data/exports/` 中积累。

## 本地部署备份规则

本地部署脚本的回滚备份统一写到 `XIAOLAN_LOCAL_ROOT/backups`。源码目录的 `bin/` 只保留当前运行需要的正式文件以及本次尚未部署的候选文件，部署完成后的历史版本不再长期保留在仓库目录。

## 提交前检查

提交前以 `git status --short` 为准。正常情况下只应看到本次准备提交的源码、脚本、配置模板、文档或任务文件；不应看到 EXE、tar.gz、部署包、日志、录音、浏览器 profile 或临时导出文件。
