# 互动业务链路替换

新正式链路为：事件接收 → 各来源调度器收集 → 独立意图请求 → 提前生成不含昵称的正文 → 已就绪正文调度 → 当前任务关联观众的后置称呼 → 简短连接模型 → 一整段 TTS → 真实可播时长与原期限复核 → 安全标点打断 → 播放回执 → 原主线续播。意图与正文使用本场冻结的方案提示词，完整有效P0一直携带；不叠加旧事实挑选、语义桶、老回答策略或另生成回归桥。连接模型只能在原正文前接上程序选定的称呼，改写、换人、失败则程序拼接。

欢迎、点赞、关注、下单相关、普通语义、对话、口令统计和双冷引导统一交给可测试状态机；强制时间互动继续保留。每个独立问题单独请求，行为最多十个来源聚合；全局四个准备槽，同优先级按房间轮转。原开场观察、各类互动开关及冷却偏好保留；问题与闲聊意图分别执行开关。可选互动失败只丢本任务，不停止主线。

任务使用租户、房间、方案、Core运行代和原事件期限做隔离；正文回执必须属于原任务和修订。新场清理上一场的临时状态；无新增数据库状态表。稳定UID隔离同名观众。真实PLAYING才计点名五分钟冷却；未播不消耗。紧急已就绪回答可撤销尚未播放的普通任务，播放中的回答不被抢。取消预约切点只解除对应未播打断，保持主线PCM时钟、游标和订阅。

澄清只用于语义或对象确有歧义，缺事实不等于反问。澄清实际开始播放才开同UID观察；完成后等待六十秒，整个对话最多一百八十秒、三轮，五秒静默聚合、最多十秒，最近五轮。新补充使未播旧结果失效；播放中的回答完成后再处理补充。意图识别为新问题会退出旧上下文。口令只在实际播出的引导中激活，按完整口令和不同UID统计，十秒静默归集，零人不播、一至两人带入下一次正文、三人起独立回应。

密度为含零分钟的十分钟窗口，1.5/3.5阈值配迟滞；普通互动每滚动六十秒最多40/30/20秒，播放失败的已播部分也结算，紧急任务例外。TTS前按正文估算，送播前探测实际WAV时长复核，不能拿字数当最终时长；超过40秒的普通成品取消。暂时没有额度保留已合成音频待切点，原期限不续命。账号池仍使用现有独立账号180次/滚动分钟与3次/滚动秒，满额切其它兼容账号、全满排队，声音未就绪不打断主线。

网页测试和内部测试同步走新意图/正文/后置连接协议，不下发直播队列或TTS。原文直读与时间互动的明确入口保持；旧代码仅保留兼容测试/其它未迁移用途，生产HTTP解意图适配器默认装载新状态机，不与旧自动互动同时执行。直播启动冻结方案提示词、声音身份与主播称呼风格，空提示词明确跳过互动，不能自动回旧事实方法。既有方案语速值按当前设置读取并冻结到本场，不替客户修改方案。
