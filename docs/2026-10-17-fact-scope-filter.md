# 事实表格按归属筛选

归属范围排序表头下添加下拉筛选，默认全部，可选公共、当前方案各活动商品链接。按稳定商品ID匹配，链接标签自然数字排序，排除其他租户/方案及停用商品。存在未指定归属/失效商品关联时提供各自选项，不把它们算作公共。

筛选仅影响表格显示，保留完整formalFacts用于初始化、保存及其他既有业务；排序继续基于原完整列表后筛选，不修改数组、事实归属或版本。按可见行显示序号/隔行颜色，总条数保留并补充当前显示条数。无匹配时保留表头供切换条件，显示空结果提示。编辑/新增/保存中禁用筛选，切换租户/房间/方案重置全部，失效选项消失时回退全部。开始添加恢复全部以显示未归属新事实，不自动继承筛选为事实归属；风险定位及定向修改遇到隐藏事实时恢复全部。
