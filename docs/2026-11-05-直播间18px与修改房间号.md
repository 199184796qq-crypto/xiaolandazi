# 直播间18px与修改房间号

状态：本地实现和验证完成；未提交、推送或部署，未代客户实际修改房间号。

直播间列表及卡片、表格、控件和本页弹窗统一18px；字号作用范围限本页面，不更改其它页面的全局字号。卡片房间号后新增“修改房间号”铅笔，保留原复制按钮；点击不进入公屏。弹窗支持当前值、输入房间号或抖音直播链接、保存、取消、Esc、焦点约束及失败保留草稿。保存禁重复点击，按服务器回执更新卡片和本账号本地缓存。迟到列表不覆盖刚保存的新号，切换账号或卸载后的保存响应不更新新会话。

仅客户本人可修改自己的直播间。Management校验登录、客户身份/租户、删除生命周期、输入及正在运行/暂停的数据库场次；Core再次校验租户、真实智能体/音频状态，存储层与连接控制共享生命周期锁，并在事务中锁定房间行、校验监控已停止和原房间号CAS。重复号由已有租户+平台+房间号唯一键拦截，事务失败不改变有效身份。只支持有效字母/数字/下划线/短横线、最多128字符；抖音直播链接只提取合法站点路径，不访问分享链接或外部网络。

修改external_room_id时同步更新source_url为新抖音直播链接，清空旧实时人数和最近弹幕时间。内部room.id、租户、房间名称、设备、方案和历史引用保持。不会自动断开、停播、重连、生成声音或调用模型；已有连接/工作中/暂停的直播必须先结束并停止连接。新增Management/Core配套PATCH /rooms/{roomID}/number接口，部署时须配套两端与桌面前端；无需数据库迁移。
