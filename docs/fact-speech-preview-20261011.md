# 事实话术预览

事实依据的已保存行在修改前提供“话术预览”。打开原生模态弹窗后，读取当前租户、方案、直播间和事实版本，使用真实 mainline_angle_plan / mainline_text 口播链路生成文字。模型只接收所选一级事实、必要条件、禁止说法、参考表达、已确认且带商品范围的纠正规则、当前主播表达标尺及有效 P0，不加载二级故事资料。当前方案未确认风格或未配置真实口播模型时明确提示。

预览不启动房间、接入播音、推进轮盘、写入方向资产或采纳方案内容。已有模型请求日志照常保留。关闭弹窗中止请求并恢复原焦点；重新生成重新读取当前母版。来源版本在模型调用前后核对，已修改或删除的事实不能被作为当前预览结果展示。租户、事实和版本关系由程序维护，不让模型返回内部标识。

复用现有 P0 语义审查和事实边界审查；审核问题保留已生成文字并展示原因，不能将未完成审查标为通过。事实表格保留顶部对齐、表达说明折叠及修改删除行为，操作列为新增按钮留出空间。
