# 模板选用自动填充占位符

用户选用六标签中任一模板时，客户模板只读 GET 按该方案已保存的资料和现有系统内置值提供填充预览。确认使用将同一预览写入当前页草稿，仍由顶部保存方案统一采用。后台模板原文和目录版本不修改，不调用模型、TTS 或 ASR，不自动保存客户方案。

已知单值按名称替换，可识别两侧空格；`直播间名`/`方案名称`来自当前方案，主播/表达等沿用系统已有内置值，业务与行业来自当前方案业务资料，有效商品、福利、事实来自同租户同方案。`商品`/`福利`块仅在存在有效值时替换。未知、缺值、空白值及改写运行期占位符保留原文，包括所在行、标点、格式和空白。替换结果不再次解析，资料中含占位符、HTML 或 `$1` 均作为普通文字。

方案访问和租户检查先于资料读取；读取失败明确报错并保留草稿。选择请求的迟到/取消/切方案隔离继续有效。替换后超过20000字或60000字节时显示原因并禁止确认，不截断正文，不覆盖草稿。前端旧后台兼容时仍使用原文；新后台提供 `rendered_content`，`content` 始终是模板原文。

旧母版渲染/生成接口保持兼容；其会删除未知槽或按开关调用模型，因此本功能不调用该接口。DS 负责的旧渲染及业务资料文件只读保留，不编辑或代提交。部署和验证回执见 `E:/直播伴播-local/prompt-template-fill-20261105`。
