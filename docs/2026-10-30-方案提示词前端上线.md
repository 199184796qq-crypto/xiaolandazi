# 方案提示词前端上线

用户授权“提交上线”。本轮只发布方案提示词建立、手动保存与确认后重新生成的前端；后台和母版由 DS 先前上线，本轮保留实际运行版本，不发布本地其他后台修改或待发布的大屏查询修复。

## 源码与范围

提交包含方案提示词编辑器、专项浏览器脚本、父页面接入，以及 DS 已上线的提示词导航和三个 API 封装依赖。API 的请求及 get/save 行为不变，未代用户修改已有提示词。

发布前从独立目录重建实际前驱前端，保留原文件换行字节：web 和 web-desktop 共 100 个产物与线上逐字节一致。初次归档遗漏 shared 导致构建失败，补齐后 Git 归档的换行归一化导致指纹不同；均已保留初始记录，最终以完整原始字节重建匹配，不以 Git 提交号推断已发布页面。

## 验证与发布

固定候选的类型、生产构建、真实父页面 10 组浏览器交互，以及发布后公网资源、鉴权、三服务健康、完整前端备份和非目标文件核验均以本轮证据为准。未使用生产账号保存方案，未开停直播或调用付费模型、TTS。

发布仅替换 web/web-desktop 入口并增加有内容哈希的资源，保留旧资源、客户/销售端、后台二进制、配置、母版及客户数据；共享发布锁内再次核对实际 current、文件、进程和 Nginx 指纹，不重启任何服务。
