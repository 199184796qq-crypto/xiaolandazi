## 唯一未完成项：销售子域

当前 `sales.xiaolandaizi.cn` 尚无 DNS A 记录，因此销售入口暂未对外启用。

需要在 DNS 增加：

```text
类型: A
主机记录: sales
记录值: 47.114.55.117
```

DNS 生效后，在开发机运行：

```powershell
.\scripts\enable-sales-production.ps1
```

该命令会自动完成：DNS 校验 -> Certbot 申请 HTTPS 证书 -> 安装销售 Nginx -> 完整生产冒烟测试。服务器 `certbot.timer` 已确认 enabled + active。
