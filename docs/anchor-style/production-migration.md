## 不变的边界

- 项目 MD 是母版，递归发布并校验 SHA；主播/方案资产按租户与版本写数据库。
- 事实包由程序组装。链接、事实、福利变化自动更新，不调用模型；卖点角度挖掘在初始化时调用模型。
- 模型选择和 Alibaba Agent 配置只在后台系统设置；客户页面不显示模型请求/原始返回，后端仍记录双向日志。
- 所有模型请求：稳定母版/规则前置，动态样本/事实/历史/本轮任务后置；不改变对话角色。
- 本场大循环、采纳记忆、1000 字窗口仅 Redis，结束清理，宕机重新开始。
- 试听不绑定直播间、不记直播费用，客户最多 120 秒，授权运维不限；不能仅由前端限制。
- 正式直播独立运行，生成完整声音/SRT/语义时间轴资产，通过主线适配层交给 Core，保持安全边界切换。
- P0 打回局部重写最多三次；P1 证据待确认不等于已经核验。来源修改使旧确认失效。
