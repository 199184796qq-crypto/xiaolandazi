# 主播管理卡片与四种展示头像

## 功能

主播管理左侧卡片按用户参考图改为蓝紫渐变、圆形耳机头像、独立名称编辑、样本/训练数量、删除、绑定及个性插件入口。头像下拉：男、女、中年男、中年女。旧主播默认女头像，不根据名字或风格推断性别。

头像通过 PATCH /api/v1/live-anchor-styles/{styleID}/avatar 保存至 live_anchor_styles.avatar_type，按 tenant_id + styleID 授权隔离。窄字段更新，不改名称、简介、样本、训练、风格、音色和方案事实。选择时显示已保存值，保存中禁用，成功再更新；失败保留原头像。
