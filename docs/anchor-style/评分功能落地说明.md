# 测试台评分功能（dynamic-score-v2）

## 使用流程

1. 粘贴或上传原始主播样本，选择分析模型，点击“开始调教”。
2. 风格元提示词成功保存后，用独立下拉框选择的模型、同一样本和定性提取 MD 生成定性结果，再由程序实测原样本并合成评分基准。失败可单独重试，不必重做元提示词。所有已启用模型均可选择，浏览器记住选择；仅首次默认推荐 DeepSeek 4（优先 Pro）。显式选择的模型不可用时会报错，不会悄悄换到其他模型。
3. 页面分开展示原始请求、不可修改的模型原始返回和程序校对后的基准 JSON，两份结果均可下载。定性字段可以编辑；确认时程序重新计算量化字段，不采纳模型或人工填入的估数。校对失败也保存原始返回和失败原因。
4. 分别确认风格元提示词和评分基准。基准作为版本资产保存至云数据库 live_anchor_style_scorecards，绑定当前方案和风格资产、记录样本 SHA256。
5. 阿里连续会话或普通 API 每次返回后，调用程序评分接口；直接展示评分 JSON（八项分数、实际值、基准值、扣分理由），不再逐项画表格。
6. 已有旧表点击“按原始返回重新校对（不调用模型）”，生成新草稿后再确认。旧版本和原始返回不覆盖。样本从保存的全文或旧请求中恢复，SHA256 不匹配则拒绝校对。

## 统计及规则补全

这些定义用于补全文档未给出公式的部分，不预设任何主播的具体风格：

- 字符分母采用 Unicode 字符数，包含标点，排除空白。词频与生成段采用同一口径，每百字频次保留四位小数。
- 模型只识别词、功能、场景、原句、情绪依据和禁用词；程序决定所有次数、密度、配比和主次排序。排序按实测次数降序，并列按词典序。模型原始返回逐字保留，不覆盖。
- 模型提供平均分句长度区间；程序实测精确平均值，两者分别保存、展示，打分使用实测值。
- 同组词采用最长优先、不重叠匹配。自指只认“我们家”类结构词，裸“我／我们”即使模型列出也排除，并单独展示排除项次数。
- “了”默认只单列次数，不进入语气词配比和打分。可通过界面开关选择计入，切换后必须重新校对并确认；本版没有降权模式。
- 缩略称呼只在样本出现时建立别名；避免把完整称呼中的子串误当别名。其他别名可在 JSON 的“称呼体系／称呼别名”确认。
- 样本未定义或频次为零的风格特征不扣分。不适用维度显示“不适用、不扣分”，保留满分名额。
- 单段独立评分；不会拿上一段的累计偏差扣本段分数。
- 八维满分依次为 15、15、15、15、15、10、10、5，合计 100。
- 主力归零扣12与被反超扣8取重项，不叠加；归零不再叠加密度扣分。非零且密度低于50%扣4。主力占比相对目标偏离超过20%扣4，被反超时不重复扣配比。单维扣分封顶。
- 称呼、自指与句式阈值沿用原始规格。原样本数值与本段频次同精度比较，避免因四舍五入对原样本扣分。
- 情绪权重：问句高为8/7，其他为3/12；标点缺口扣分为 ceil(权重 × (目标密度-实际密度) / 目标密度)。问句低不扣问号，目标0不扣。这里只测标点节奏，不判断实际声音情绪。
- 比价维度只用于有价格习惯且当前任务涉及价格、或文本出现价格的段落。数字卡壳采用可解释的词面标记检测，不判断商品价格真假或算术事实。
- 回环缺失扣5，出现一次通常扣2、高回环扣3，两者不叠加；低回环不强迫短段重复。
- 环节位置用呼告／行动词面检测。无提示扣2；行动提示只出现在文本前1/3扣2。不编造新的主播称呼。
- 当前八维评分不额外给方言、禁用词单独加扣分；这些仍保存在原基准 JSON 中。页面明确展示当前评分覆盖的八项。

## 一致性与版本

程序不调用评分模型。相同文本、确认基准和规则版本会得到逐字节一致的评分 JSON。结果包含使用的基准快照、基准资产 ID、样本与待评分话术 SHA256，可随完整测试导出。

换方案自动读取该方案当前基准。更换风格资产后，旧基准不能用于新主播；提取、确认和评分均检查关联版本。历史基准保留在数据库。校对版本为 qualitative-quantitative-v2，旧版基准须重新校对确认才能用于本版评分。
