# 互动纠正与用户事实审核权（2026-10-09）

## 已确认的边界
用户原话：“你只能去审核违规这些问题，不能审核事实，事实交给用户审核。”
用户同时明确确认：“我们确实是默认抽真空。”

事实由用户确认；审核模型只处理违规表达及内部信息泄漏。模型对事实的疑问是建议，不具有否决权。默认抽真空已经作为本次开发、测试与后续交接的用户确认事实记录；本次没有直接改写生产数据库的商品事实。

## 本地实现
- 初始化：模型结合完整商品资料、事实、福利和已有纠正，生成待用户确认的建议。建议不自动采用，允许没有新增建议。
- 直播：同一次回答返回正文及少量建议元数据。元数据不会单独触发强制重审、拒绝播出或改变队列；格式错误单独留诊断和原始返回，不否决已取得的有效正文。
- 用户处理：复用现有学习会话，用户填写纠正、预览并确认采用；业务事实也可由用户确认采用，不再因模型归类为事实而拒绝。纠正按方案隔离，沿用现有记忆更新与热同步。
- 事实审核权：撤掉直播终审中按资料关键词裁决物流、渠道等事实的检查和自动替换；纠正流程不再由历史频次或额外审校模型改写用户明确确认的内容。保留违规表达检查和内部信息过滤。
- 原有生成仍读取事实和用户纠正；审核权限变化不意味着把模型临时举例自动保存为事实。
- 打断切点、队列优先级、回归桥和连续音流架构没有新增改造。
