# 基准表字段分工 —— 模型出「定性」，程序出「量化」

> 结论先行：**一张基准表里，凡是「数数、算比例、数每百字」的字段，一律由程序算；大模型只负责「用原词原句描述规律」这类定性字段。**
> 这是上一轮反复踩坑（分母 1200/2340/1302/697 每次都不一样、感叹号估 27 实际 2、主次写反）后的铁律。

---

## 一、三条铁律（不变量）

1. **程序实测的数永远是对的。** 字数、每个语气词/称呼/自指词的总次数、问号感叹号个数、每百字值、配比、主次排序——这些全部由程序对「原话术全文」用正则一次性数出来，零漂移、可复现。
2. **大模型的「核对表」永远是估数。** 大模型数数必漂（分母每次不同、次数靠估、比例算错）。所以**不让大模型数数**——它不产任何数字，只产「词 + 功能 + 场景 + 依据」这类定性描述。
3. **「了」是否算语气词，口径未定，先单列成开关，不进白名单。** 等老板定夺：是语法助词（不数）还是语气词（数）。在定之前，程序把「了」单独统计、单独展示，不并入任何语气词配比。

## 二、字段分工表

### A. 程序出（量化层）—— 喂给程序的原话术全文，程序正则数数

| 字段 | 说明 | 谁出 |
|---|---|---|
| 样本总字数 N | 去空白后的总字符数，唯一分母 | 程序 |
| 每个语气词出现次数 | 白名单内每个语气词各数一遍（「了」单列） | 程序 |
| 每个称呼出现次数（含缩略合并） | 全称+缩略合并计数 | 程序 |
| 自指词出现次数 | 只算「我们家」类，不含我/我们 | 程序 |
| 问号数 / 感叹号数 | 逐字符数 | 程序 |
| 每百字_各项 | 总数 ÷ N × 100 | 程序 |
| 语气词配比 | 主力:辅助 = 实际比例 | 程序 |
| 主次排序 | 谁最多谁就是主力，机器判定，不靠感觉 | 程序 |

### B. 模型出（定性层）—— 喂给大模型原话术全文，模型只看「怎么用」不看「用几次」

| 字段 | 说明 | 谁出 |
|---|---|---|
| 各语气词的功能 | 强调/催促/舒缓/解释…（从上下文推断，不数数） | 模型 |
| 称呼使用场景 | 谁在什么情况下被怎么称呼 | 模型 |
| 自指词清单 + 「我们是否=我们家」判断 | 只列词 + 判断，不数次数 | 模型 |
| 平均分句长度区间 | 只给「约 8~25 字」这种区间，不数精确值 | 模型 |
| 长句短句搭配规律 | 定性描述 | 模型 |
| 确认句库 / 算账句式 / 比价锚点 / 方言词 / 口头禅 / 回环短语 | 摘原词原句（这是模型强项） | 模型 |
| 价格表述方式 / 是否爱算账 | 三选一 / 布尔判断 | 模型 |
| 情绪特征 + 判断依据 + 情绪高点位置 | 定性，但依据要可验证 | 模型 |
| 禁用词（反推） | 反推书面客服语/过渡词 | 模型 |

## 四、两条流水线怎么接

```
【基准表生成】
原话术全文 ──┬──▶ 程序正则统计（量化层 A）──┐
             │                              ├──▶ 合并成最终基准表 ──▶ 打分器
             └──▶ 大模型定性提取（定性层 B）──┘

【打分回灌】
新生成话术 ──▶ 程序统计（量化）──▶ 对照基准表打分 ──▶ 找出最致命的 1 项 ──▶ 回灌提示词
```

关键点：**程序全程是「唯一数数的角色」**，大模型在打分和回灌里也不数数——打分靠程序把新话术的实测数跟基准表比，回灌模板里的「实际值/目标值」也都是程序填的数字。

---

## 五、待老板定夺的 1 个口径

**「了」到底算不算语气词？**

- **A｜算语气词**：程序把「了」并入语气词白名单一起数，进配比、进每百字。
- **B｜不算（默认倾向）**：「了」是语法助词，只单列次数展示，不影响任何配比和打分。
- **C｜算但降权**：进白名单，但打分时权重打折。

默认先按 **B** 走（单列展示、不进配比），老板定了再改。
