# 目标字数自动循环测试

## 当前界面

打开本地 `http://127.0.0.1:5273/operations/live/style-workbench`，默认只展示方案、目标字数、开始／暂停／继续按钮，以及一个累计话术文本框。旧的风格分析、事实包、评分、每轮请求等中间状态默认隐藏，点击“显示设置与单步调试”才展示。原文每完成一段就追加，不做拼接改写或截断。

## 调度与闭环

1. 读取当前方案已确认的风格元提示词、评分基准、事实包和卖点轮盘。使用所选阿里母版及已有 Session；没有 Session 时在开始后创建。
2. 按整个 Session 已收到话术的任务历史选下一格。默认禁止选最近2段讲过的卖点，以及最近5段讲过的卖点×角度组合；间隔可调整。优先未讲／少讲组合，公平轮换；跨圈不清空记忆。池不足以满足间隔时停止，绝不偷偷放宽。
3. 首轮按现有协议注入风格、事实、任务；后续沿用简短卖点×角度消息，若有本段生成的单项回灌则附到下一轮。
4. 收到完整原文立即追加到累计框，记录任务及请求；随后程序评分、填回灌模板。无问题时清空回灌，避免旧提示重复累积。
5. 串行继续下一格，累计字数达到或超过目标后停止。字数为Unicode字符数，含标点、不含空白；最后一段完整保留，因此允许略超过目标。自动模式独立单段上限默认300字，最后剩余不足80时仍请求最多80字，避免违反现有接口限制。

## 暂停、恢复及边界

- 暂停不是取消阿里已经受理的请求：收好当前原文、评分、回灌后停止，不再发下一轮。
- 同一方案的 Session、原文、任务记忆、请求、评分和自动进度保存在本地浏览器；评分基准快照去重保存。刷新后只恢复为暂停，不自动产生新的收费请求。
- 切换方案保存旧方案会话，不自动归档；回到该方案可以恢复记录。显式“归档并重建”／“重置测试”会清理该方案本地测试记录，操作前可导出。
- 评分失败保留原文和记忆。继续时先补做上一段评分，不重生成；回灌模板错误也停止。
- 生成超时、刷新时尚有在途请求等结果不确定情况阻止继续，以免重发产生重复段落。需在高级调试核对／归档重建，不自动猜测成功或失败。
- 资产变化、空返回、无法满足间隔、本地保存失败、安全轮数上限均停止。开始或继续必须由用户点击；不会后台定时自动恢复。
- 当前是测试页面调度：页面保留运行时才能持续驱动。它不是服务器守护任务，也不保证跨设备共享调度记忆。正式房间生产调度的服务器持久化不在本次测试界面实现中。

## 验证

`node --test tests/anchorStyleAutoRun.test.ts` 验证后端索引一致性、80轮记忆、串行顺序、回灌下一轮生效、目标停止、暂停、评分失败不重生成、生成失败不虚增、上下文保护、空返回保护及本地数据还原。`npm run build` 校验 Vue 和 TypeScript。

本次实现验证不请求真实模型；真实闭环由用户选定目标字数后点击开始测试，会产生阿里运行时及模型费用。
