# 挖掘机公共与商品分池编辑

## 用户要求与行为

“已经挖掘出来的”下方、展开/收缩按钮左侧增加内容范围下拉框。默认公共内容，其余选项按当前方案商品稳定ID列出商品链接号和名称；原始挖掘素材另列保留。列表、卖点数量、角度数量随范围切换。

公共与单品列表读取真实内容池任务，不靠文本中的链接号推测归属。公共包含各公共适用组，编辑请求携带准确的池key和任务ID；商品仅展示对应专属池，不混入其他商品。

## 保存与版本

新增 POST content-pools/edit 接口，沿用租户、方案、房间与运维授权检查。编辑保留任务事实引用和池适用商品；新增角度沿用所选卖点的引用。用户负责事实内容，没有新增事实真假审核或模型调用。

修改、删除、新增仅作用于所选池和所选任务，保存为新的完整不可变内容版本；旧总素材、其他池、已保存智能体及当前场次均不改写。用户另行保存智能体后，下次开播采用。当前资料变化或生成正在进行时，先更新内容池，再编辑。

事务锁定方案资料revision并核对原内容set_id。并发修改只允许一个提交；编辑推进revision，阻止同一时间保存陈旧智能体。前端保留编辑快照和冲突草稿，编辑期间锁定范围切换，换房间丢弃旧请求结果。

## 验证

- 管理服务 go test ./... 通过；Vue类型检查、Vite构建通过。
- 真实组件本地浏览器：公共/整只/半只/空商品切换，整只编辑准确投递，冲突保留草稿，资料变化时编辑锁定通过。
