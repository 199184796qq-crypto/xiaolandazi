# 保存即生效（2026-10-08）

- 智能体方案只有保存一步，不再提供发布或回滚入口。开播读取当前租户、直播间、所选方案及内容模式的最新成功保存快照；历史版本不会被自动回退使用。
- 保存校验保持不变：音色、正式声音包、方案快照、派生安全依据及商品范围必须通过。快照与兼容生效指针同事务提交，失败不产生待发布状态，不改变原方案。
- 正在运行的场次保留启动快照。新保存方案用于下一次开始；版本 ID 更新不再取消当前生成器。切换方案关联、撤销授权及原始事实/福利失效校验仍有效。
- 每个租户/方案/直播间/内容模式保留当前快照及最近三个旧快照。正在直播或暂停时延迟清理；保存及停止时自动清理。共享音频、原始资料、审核确认及历史事件不删除；仍被有效指针或未结束内容刷新任务引用的快照受到保护。
- 历史表字段 `published` 和 `published_at` 仅兼容现有 Core/管理协议，不再代表额外的用户操作。旧发布接口只读取最新保存结果，拒绝选用旧版本。
- 进度/生成器租约继续采用进程隔离 Redis，服务重启不恢复旧场次。部署管理服务前必须检查所有场次已停止。
