# 方案提示词删除模式

主播人设、事实依据、红线禁止、直播话术要求、互动回答要求、话术规划六个页签共用。

结构化显示工具栏依次为“编辑模型”“添加节点”“删除模式”。默认不显示删除入口，点击“删除模式”后按钮变为“完成删除”，节点和每个键值行（含正文）右上角显示红色抖动×角标；点击角标直接删除对应节点及其全部内容，或单独删除该键名及其内容。旧“删除节点”“删除键值”“删除正文”文字按钮和旧二次确认已撤下。角标保留可访问名称、键盘操作和焦点提示，系统设置减少动态时停止抖动。

退出删除模式、切换页签/方案/整段显示、开始保存/拉取或收到新原稿时关闭角标。只修改当前草稿，仍通过顶部“保存方案”统一采用。保留双显示原文互通、来源元数据排除、内联新增、只读和迟到事件隔离，不新增后台字段、模型规则或token。

验证通过：10组删除模式真实父页测试、12组双模式、26组结构化编辑、18组按页拉取及15组统一保存/维护页，共81组浏览器回归，无浏览器错误或外部业务请求；23项解析/编译、类型检查和生产构建通过。覆盖六页字段/正文/整节点精确删除、退出与切换隔离、只读与迟到旧角标、保存刷新、四宽度位置和键盘/减少动态支持。

准确前驱两端各53项前端资源独立重建一致，4442项旧前端完整备份逐项匹配，10项离线发布空闲守卫通过。实现与验证证据 E:/直播伴播-local/prompt-delete-mode-20261105；发布证据 E:/直播伴播-local/prompt-delete-mode-release-20261105。验证和上线回执完成后补充。
