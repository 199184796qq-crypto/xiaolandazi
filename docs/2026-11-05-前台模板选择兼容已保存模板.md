# 前台模板选择接通已保存模板

前台使用后台「提示词维护」保存的六标签模板。2026-11-05 线上原六份模板仍在旧存储中，新目录没有记录，且后续 Management 覆盖缺少新目录路由，导致模板选择无法读取。

恢复目录 API，并对尚无目录行的标签读取其实际保存的旧模板，以「默认模板」供选择。只读取数据库已有文本；保留原文、空白和占位符，不调用模型、不自动补写目录。未保存过的标签仍为空。

前台按当前标签列出模板、预览并确认，只替换当前页草稿，顶部「保存方案」统一采用。原有双模式编辑、内联新增、删除模式与异步隔离保持。
