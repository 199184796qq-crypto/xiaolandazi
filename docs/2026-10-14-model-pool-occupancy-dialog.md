# 模型池占用详情弹窗

账号池主页面保留账号列表与名额汇总，不再展开房间明细。点击一行“查看占用”弹出该账号模型的详情，显示客户、直播间、AI状态与分配时间；不同账号模型的记录按池记录编号隔离。

默认每页10个房间，可选20或50个，显示当前页/总页数及上一页/下一页。切换每页数量或重新打开从第一页开始；刷新后占用减少，页码收回到有效范围。零占用显示空态，暂停AI标记“已暂停 · 保留名额”。
