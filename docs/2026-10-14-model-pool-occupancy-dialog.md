# 模型池占用详情弹窗

账号池主页面保留账号列表与名额汇总，不再展开房间明细。点击一行“查看占用”弹出该账号模型的详情，显示客户、直播间、AI状态与分配时间；不同账号模型的记录按池记录编号隔离。

默认每页10个房间，可选20或50个，显示当前页/总页数及上一页/下一页。切换每页数量或重新打开从第一页开始；刷新后占用减少，页码收回到有效范围。零占用显示空态，暂停AI标记“已暂停 · 保留名额”。

支持关闭按钮、点击遮罩和Esc收起，恢复触发按钮焦点；Tab留在弹窗内。手机改为详情卡片，房间区域内部滚动，翻页操作保持可见。页面卸载移除键盘监听并恢复页面滚动。

只改显示和翻页，不调整API、账号配置、100个名额、租约或AI。沿用现有读取接口，打开/刷新详情更新占用快照。本次仅发布两个桌面入口和新增哈希资源，不重启服务、不替换后端、提示词、手机页或Nginx。源码已合入WorkBuddy c0ad094，服务器同名release中的后续管理二进制原样继承。

验证使用24条虚拟占用（账号A 23条、账号C 1条），覆盖按账号隔离、10/20/50分页、末页、刷新后页数减少、零占用、关闭/焦点及390px布局，保留账号编辑/导入/密钥不回显的原有浏览器回归。另有21项已有前端回归和生产构建。生产证明在本聊天work/model-pool-occupancy-proof。
