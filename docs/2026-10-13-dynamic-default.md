# AI动态生成默认可用

2026-10-13 用户要求：所有直播间默认开通AI动态生成高级模式，不再逐房间由运维授予该功能。

## 行为

- 已有和新建房间的可用模式均包括动态生成。历史 dynamic_authorized=0 不再拦截选择、发布、实时生成或自动更新；接口保留旧字段并恒为true，旧来源字段对外返回default。
- 功能可用与选择模式分开：发布没有批量修改房间的selected_mode、更新周期、自动更新开关或缓存设置，不启动直播。动态生成仍由用户/有客户协助授权的运维选择。
- 运维页面删除逐房间开通复选框，保存不再发送开通字段。旧网页即使发送dynamic_authorized=false，也不会关闭功能或强制回退房间模式。
- 原有客户账号归属、运维岗位权限、客户对具体直播间的协助授权、方案绑定范围、版本/模式校验、CAS、删除守卫和审计继续生效。
- 旧数据库字段保留，读取不改写历史。新模式写入记录默认可用；新建数据库表的列默认值为1。后台调度按已选择的动态模式、实际运行、自动更新设置、发布内容和安全切换条件处理，不再读取逐房间功能授权。
- 系统默认直播模式继续保持原约定；动态模式仍按直播间明确选择。
