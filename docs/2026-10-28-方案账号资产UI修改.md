# 方案独立于房间：UI与后台修改记录

2026-10-28，用户最终明确的业务规则优先：方案是账号资产；房间仅选择开播方案。声音、事实、主播风格、问题库和读写规则属于方案，同一方案跨房间共用同一份配置。不提供房间对方案声音或风格的覆盖。

## 变更内容

- 方案编辑页移除房间选择栏和“为当前直播间选择此方案”；编辑器切换方案只改变编辑对象，选用操作保留在直播页。账号没有任何房间也可创建、编辑、恢复并保存方案。新建默认名不再包含房间名称，编辑偏好按账号和租户保存。
- 声音中心只向方案编辑状态写入声音；普通保存保留情感、风格和语速。保存前现查可用状态，失效时拦截并列出可选音色，不自动替换到另一声音。后台严格校验克隆绑定身份及ready状态，官方声音走已配置目录。
- 新增按租户+方案的内容模式与读写规则表及API；问题库、目的和读写规则面板直接使用方案API，不再要求方案先被房间选用。旧房间路径仅作兼容解析入口，历史记录保留，不自动从某个房间导入规则。
- 新保存版本room_id为0；版本列表和工作区不要求房间。正式取版不再按房间模式筛选，房间仅通过选择关系引用最新保存版本。保存不更新旧房间发布指针；有活动场次时保守延后清理历史版本。
- 文稿生成、审核、主播风格测试、原始录音及声音字幕资产处理去掉房间绑定前提，仍校验租户、方案及媒体归属，保留P0与事实约束。试听声音只取该方案保存的身份及方案语速，忽略旧voice_source_room_id覆盖。
- 互动待播声音不再回退房间声音或系统默认；读写规则缓存按租户+方案+版本区分。场次、账单和处理历史仍保留原追溯身份，本轮没有搬移或删除历史业务数据。
