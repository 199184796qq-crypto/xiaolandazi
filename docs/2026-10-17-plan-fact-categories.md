# 事实分类请求按编辑方案加载

当前事实分类请求原来只有租户/授权直播间范围，没有传方案ID，因而无法使用后端已提供的业务模式与行业分类。现在 `loadFactCategories({ planId })` 生成：

```text
GET /api/v1/live-agent-fact-categories?plan_id=5
```

传入值为正在编辑的方案ID，不取实际运行场次或第一个绑定方案；未选方案、非法编号保留原无参数回退。主页面初次恢复/切换方案、重试和资料更新时重新请求，分类pending去重及迟到响应校验也纳入方案。资料补全、互动补事实及助手的分类调用一起传递各自有效方案，避免其中的无参数请求覆盖当前分类。

## 范围

本次仅按用户任务补分类请求及方案隔离。当前源码中 `FormalFactTypePlaceholder.vue` 依然是空禁用下拉框；保留此前交给WorkBuddy连接数据和保存的职责，本次没有改变列、类型字段、分类值或四层规范化业务。前端不内置17个餐饮分类，不修改后端，也不能据本次变更声称事实类型下拉已经完成选项显示及保存接入。
