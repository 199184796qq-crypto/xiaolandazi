# 提示词维护：@ 插入内置占位符

2026-11-05。状态：准备发布，尚未激活。

在六份母版编辑框的光标处输入 `@`，弹出当前母版可用的内置占位符。继续输入中文名称可筛选；点击候选或用上下键选择、Enter / Tab 插入，Esc 关闭。插入替换当前 `@查询`，保留前后文字，光标落在插入内容后。不会自动保存，仍由原来的“保存母版”提交全部六份原文及 revision，再由方案“拉取提示词”和“保存方案”采用。

## 来自程序实际替换路径的目录

目录由 Management 的 `planPromptPlaceholderCatalog` 返回，GET 和保存成功的 PUT 均携带 `placeholders`；目录不参与母版原文、revision 或保存请求。服务显式返回的目录优先；当前服务缺少该字段时，前端使用同版兼容目录快照。快照来自后端真实渲染测试输出，并有逐字相等测试，不能另写一套不受验证的名称。显式空目录不启用兼容快照。
