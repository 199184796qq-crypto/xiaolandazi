# 本地开发环境与跨平台约束

## 固定工具链

- Go: 1.27.1
- Node.js: 24.21.0 LTS
- pnpm: 11.25.0
- 前端: Vue 3 + TypeScript + Vite
- 基础设施: Docker Compose
- MySQL: 8.4 LTS
- Redis: 8.2
- FFmpeg: 外部可执行文件，通过 PATH 或配置定位

## 平台目标

开发环境可以是 Windows、macOS 或 Linux。
生产服务端优先 Linux amd64/arm64。
设备端协议不得绑定 CPU 架构和操作系统。

## 强制约束

1. 源码不得写死 Windows 盘符或反斜杠绝对路径。
2. 服务地址、数据库、Redis、LLM/TTS Key 全部走配置。
3. Go 文件路径使用 filepath 包。
4. API/设备协议统一 UTF-8 + JSON。
5. 时间在服务内部统一 UTC/RFC3339，展示层再做时区转换。
6. 文本文件统一 LF；PowerShell/Windows 批处理例外。
7. 服务端业务核心避免 Windows-only API。
8. CGO 默认关闭，除非后续有明确、经过评估的必要。
9. 浏览器管理端与设备模拟器不依赖本地桌面专属接口。
10. 真盒子与模拟器必须实现同一份 WebSocket 协议。

## Windows 当前开发方式

- Go 后端：Windows 原生进程
- admin-web：Node 24 + pnpm
- device-simulator：Node 24 + pnpm
- MySQL/Redis：Docker Linux 容器
- 音频：项目 data/audio 相对目录

## Linux 生产迁移

业务代码保持不变，主要变化为环境变量、数据卷、网络地址和服务编排。
