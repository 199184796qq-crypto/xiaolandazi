# TTS账户池与统一调度

状态：已实施并完成本地验证，未部署生产。范围为当前使用的阿里TTS合成，保留原有模型、音频下载、归档和计费口径；腾讯声音沿用现有路径。

## 分配规则

1. 房间的合成请求先进入统一调度器。每个独立阿里云主账号分别计数：滚动60秒最多180次，滚动1秒最多3次，同时平滑请求起始时间。管理员可以调低，不能突破这两个上限。
2. 优先使用当前账号；该账号没有额度时，检查下一个能合成目标音色的账号。有可用账号即发送，全部兼容账号都无额度才等待。
3. 按账号合计所有房间、模型和Management进程的准入请求，不因多Key、多模型、请求完成、失败或服务重启而重新获得窗口内额度。这一期合并阿里模型计数，较供应商按模型分别限流更保守。
4. 数据库中的共享锁和数据库时钟使并发领取串行判定；等待顺序按可使用的账号保持先来先服务。暂停的场次和没有兼容音色的请求不挡住其他有可用账号的房间。
5. 上限1000条等待请求，等待最长5分钟，并受调用方原有有效期约束；互动执行仍受90秒执行期限约束。等待者持续刷新存活时间，失去存活更新超过10秒的孤儿请求在下一次调度时清理，不让退出的进程一直挡住其他房间。请求取消、进程退出、场次停止、场次身份不符或等待过期后不再发送。数据库故障也不会绕过调度器直接调用。

## 排队时继续直播

- 录音话术主线和动态生成主线都接入等待回调：当前Core缓冲低于15秒时，从本场、本版本最近已确认交付的完整音轨中追加缓存声音。只保存最近4条，不重新调用模型或TTS。
- 保留音频、正文、时间轴和切点，重复送播使用新的音轨编号；追加结果未知时使用同一个编号核对重试，避免重复追加。录音主线的缓存追加保存待确认回执，不推进正在等待合成的原文游标。
- 先核对场次所有权、方案版本和Core程序；暂停、互动挂起、场次切换或失效音频地址不继续追加。缓存重播也登记场次声音资产。
- 互动声音没就绪时不发起音频打断。额度恢复、声音就绪并通过现有有效性检查后才进入原送播流程；取消或过期的互动不补播。
- 全冷启动没有合格声音、缓存地址失效或Core不可达时，只能等待有效供料。不能把“不主动停播”理解为在任何故障下都能保证有声；本轮没有实机听感验收。

## 后台配置

入口：系统设置 → AI与智能体 → TTS账户池与调度。

首次启动安全登记现用环境凭据，无需再次输入原Key。每个账号可维护名称、启停、180以内的每分钟上限和3以内的每秒上限；页面显示各自滚动用量、正在合成数量和最早50条等待请求。

添加备用账号前，先补齐当前账号真实的阿里云**主账号UID**。同一个UID或同一个Key不能登记第二份额度；已登记的真实UID不能改成其他账号。需要其他独立账号时新增条目，旧条目可以停用。不同RAM用户、工作空间或Key不能当成独立主账号。

备用账号需要输入自己的Key，以及“模型 / 方案原音色ID → 本账号对应音色ID”。克隆音色通常与账号、模型绑定，不会假定更换Key就能使用原音色。管理员应先在对应账号准备并确认同一声音，再登记映射；没有精确模型和音色对应的账号不会接到该请求。程序不自动克隆、不切换模型、不调用付费测试，也不能仅凭手工UID或映射证明供应商实际授权与音色一致。

当前账号Key留在环境中；新增账号Key使用既有 `MODEL_CONFIG_ENCRYPTION_KEY` 进行带身份绑定的加密存储。GET不返回Key、密文或Key指纹，表单保存或失败后清除新输入的Key。读取、保存仅超级系统管理员可操作，修改使用版本冲突检查。多进程须使用同一数据库和加密配置。

启用账户池后，动态主线不再临时借用文字模型账号。环境中的旧Key为空时，仍可使用后台已启用且音色匹配的TTS账号；没有配置任何可用账号时等待补充配置。未接入调度器的独立调用保留原有兼容行为。

## 费用和请求边界

调度器位于原计费观察器之前。等待期间不预留合成费用、不建立供应商连接；取得账号额度后才进入原费用准入和真实合成。互动的35秒供应商超时从取得额度后开始，原执行期限和主动取消继续有效。已有缓存重播不产生TTS费用。

供应商返回失败或结果未知时，不在本调度器内自动换账号重发；原有业务重试仍必须再次申请额度并经过现有计费幂等检查。额度按系统请求准入时间保守计算。账号若另有系统外调用、额度被供应商调整、余额/权限异常或映射配置错误，仍可能收到供应商错误；这些情况不能以“本地额度未满”证明账号一定可用。

## 实现与验证

- `internal/ttsscheduler`：等待、取消、缓存供料回调、滚动窗口和平滑准入。
- `internal/db/tts_pool.go`：账号、加密凭据、共享锁、持久队列、场次隔离与逐账号领取。
- `internal/ttsgateway/scheduler.go`：网关统一接入，使用领取账号的凭据与音色，额度后计费与超时。
- `internal/httpapi/tts_pool.go` 与 `web-console/src/views/TTSPoolSettingsView.vue`：后台管理与用量查看。
- `internal/httpapi/tts_wait_continuity.go`：排队时的已审核完整音轨续播；两种主线生产者接入。
