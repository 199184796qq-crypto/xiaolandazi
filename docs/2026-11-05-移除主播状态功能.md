# 移除主播状态功能

用户要求删除直播间偏好界面的整个“主播状态”功能。

界面保留“互动开关”和“称呼习惯”两个标签，按两列显示。删除主播状态组件、状态输入及预设选择、有效期和保存入口；同时移除公屏任务详情中的临时状态展示。

前端专用 API 和类型、Management 原 GET/PUT 路由、保存校验、存储读写方法及对应业务模型已删除。旧地址 `/api/v1/rooms/{roomID}/human-behavior-profile` 不再提供功能，实际路由测试所有读写方法均为 404。

生成阶段不再读取直播间临时状态，不再把它转成话术约束或 TTS 表达指令。任务模型删除 `human_style.state.host_state` 及其有效期；旧任务 JSON 中这些字段被忽略，两种 TTS 指令构建均验证不会受旧状态影响。方案主播风格、互动和称呼偏好、直播热度/进度与一般真人化行为继续保留。

历史 `live_room_human_behavior_profiles` 表未清空或删除；保留历史建表及删除直播间时清理历史数据的 SQL，不存在业务读取或保存入口。没有修改客户设置、缓存或提示词母版，没有生产写入和真实模型/TTS/ASR调用。
