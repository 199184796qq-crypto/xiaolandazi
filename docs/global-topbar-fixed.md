# 全系统顶部导航固定（2026-09-24）

## 范围

本轮只执行用户已确认的顶部固定需求。终端网页、超级系统管理员、管理部、财务部、销售、营销运维、仓储、售后与物流均共用 web-console/src/App.vue 的 global-topbar。固定内容为返回/面包屑、顶部业务状态、终端时长与会员、当前账户和退出按钮。登录/注册不增加业务顶部栏。

个人钱包改名与迁入个人中心、个人邀请入口迁移、邀请码卡片缩小与切角状态仍在待确认清单中，本轮不修改。

## 实现

共用顶部采用 position: sticky / top: 0，所有角色生效，不按部门逐页重复添加。顶部保留在正常文档流中，自动占据实际高度，面包屑换行或页面变化不需要硬编码占位块。下方功能切换栏与业务内容按原来的文档滚动方式滚动；不把页面标题、表头或每个卡片都固定。

顶部固定层级为80，仍低于现有智能体抽屉和会员、业务弹窗。背景为不透明的浅色，列表滚过时不透出文本。没有新增滚动监听、计数请求、数据库访问，也没有滚动后收缩或隐藏样式。

窄窗口继承原有隐藏侧栏规则，并移除对应左侧占位；顶部控制区按可用宽度自然换行。保留现有字号、账户信息和权限判断。

## 验证方法

scripts/test-global-topbar.cjs 使用独立 Chrome 用户目录和模拟 API/EventSource，在真实路由与共用 App 上测试：终端商城/收款、系统/管理、财务首页/收款、销售、运维首页/工单、仓储、维修售后、物流。对空页面只在浏览器内添加无业务内容的高度块，保证实际发生文档滚动。

断言滚动到中间、底部、回顶部时整条导航的位置、高度、宽度与背景不变，初始业务区域未被遮挡，账户与退出等控件可见，会员弹窗层级高于顶部栏。终端与财务另在1920、1280、820、390像素窗口验证。所有业务请求限于模拟读取，不操作真实账户、审批、资金或库存。

本轮无需重启后端或看门狗，不提交或推送 Git。测试及构建结果以实际命令输出为准。
