# 智能体工作台双页布局

原“生成与预览”把内容任务和初始化、试听、生成参数放在同一个长页面。现在该区域改为两个入口：

- 智能体配置：内容任务、未入池提示、待更新资料、公共池与商品专属池、已保存方案检查提示及保存操作。
- 生成与预览：初始化直播智能体、主线方式、实时文字与播放器、实时生成参数，以及原有录音主线、固定生成和全部后续模块。

通过顶部入口和返回按钮切换；初次进入显示智能体配置。沿用原模块与事件处理，保存智能体调用既有统一保存流程。页面切换使用 v-show 保持两个区域挂载，参数、展开状态和播放器不会因切换丢失。直播间或方案上下文变化时回到配置页，现有外层上下文 key 仍会隔离旧工作区。

## 验证

- 前端类型检查和生产构建通过。
- 既有导航、资料补充清单与对话 14 项回归通过。
- 使用完整 LiveStrategyView、全局样式和合成方案数据，验证两个区域分离、鼠标/键盘切换、返回按钮、参数保留、池展开状态保留、播放器 DOM 不重建和切换不发起业务写入。
- 1600、1024、390、320 像素宽度下两页均无水平溢出，每次仅显示一个页面。
- 未修改主线生成、内容池、审核、声音、保存及 P0 接口，不为布局验证调用模型或生成声音。
- 未修改主线源码的前端构建产物与当前线上 45 个资源逐项一致，确认新布局基于已部署的最新完整前端。

发布以前端实际 current 为基础，仅更新 web 和 web-desktop 两个入口、增加资源，保留旧哈希资源、后台运行文件、手机端、提示词和 Nginx。持共享发布锁并在切换前重新核对全部文件及进程指纹。
