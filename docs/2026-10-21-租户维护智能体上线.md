- `client-agent/chat` 接收当前 `plan_id`。
- 只读回答本方案事实、福利、商品、概况。
- 包邮优先读已发布版本快照（1/2/3 链接）；地区未写明确不能确认。

- system 域写命令接入现有 `live_strategy_intent` + `live_strategy_actions`：

  - 福利新增/修改/停用
  - 商品新增/修改/停用
  - 话术新增/修改/停用
  - 方案绑定/解绑/切换
- 统一“动作预览 → 确认 → 执行 → 版本号”。
- 动作卡支持按钮和文字“确认/取消”。
- `plan_id + room_id` 上下文校验；切方案/切房间旧卡失效。
