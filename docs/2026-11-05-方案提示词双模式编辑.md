# 方案提示词双模式编辑

六页方案提示词（主播人设、事实依据、红线禁止、直播话术要求、互动回答要求、话术规划）使用相同编辑器。

结构化显示保留紫色节点名、蓝色键名和可编辑的值；所有来源节点、键值、正文均可在页面内确认删除，新增节点和键值仍在页面内输入并失焦解析。移除重复页标题、测试标识、总说明、颜色图例、来源和锁定小字。

“编辑模型”按钮位于“添加节点”之前，点击后整页内容显示在一个可编辑文本框内；可修改包括节点名、键名在内的完整原文，点击“结构化显示”按当前内容重新解析。两种显示共用同一份原文，纯切换不会改写、裁剪或重新生成内容，不新增模型请求或token。无法识别的内容保留为正文。

六页独立保留显示方式和新增草稿，切方案不复用旧编辑器，迟到输入事件不能串页/串方案。未解析的新增内容保留并阻止切换；中文组合未结束时也不切换。拉取/保存期间只读，拉取成功（含相同原文）清除该页旧新增草稿。整段修改清除过时的人设来源元数据，该元数据仍不进入模型提示词。

仍须点击顶部“保存方案”统一保存。按页拉取仅更新当前请求页，原有失败保护、20,000字校验和统一保存流程保持。只调整前端，未改模型输出契约、平台母版、后台程序或数据库结构。

本地验证通过：23项原文解析与编译测试；12组新增双模式真实父页测试、26组结构化编辑、18组按页拉取及15组统一保存/维护页测试，共71组浏览器回归；类型检查和生产构建通过。覆盖六页原文互通、CRLF/空白/占位符原样、改名重解析、来源失效、IME、错误新增保留、切页/切方案迟到保护、相同内容重拉、清空保存刷新及1440/777/390/320px两种显示。无浏览器错误或外部业务请求。

准确线上前驱两端各53项前端资源独立重建一致，4392项完整前端备份逐项匹配，10项离线发布空闲守卫通过。正式发布与线上核验回执随后补充。证据目录：E:/直播伴播-local/prompt-dual-mode-20261105、E:/直播伴播-local/prompt-dual-mode-release-20261105。
