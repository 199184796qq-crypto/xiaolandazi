# 直播下载

在直播间字幕区底部，与“本场回答库”同排增加“直播下载”。面板提供整场纯文字 TXT，以及按声音开始播放时间筛选、分页查看、逐条下载音频。

用户确认以实际播放记录为准：主线、互动回答、已使用衔接语；未播放候选不导出。以已开始播放的声音片段为收录单位，保留该片段的完整文案和原声音文件，并非设备录音或逐字 ASR。TXT 不带标题、时间戳，整场查询不受声音筛选和 50 条分页影响。

数据库增加 live_session_speech_assets，保存不可变输出记录。租户、房间、场次均参与保存、查询和下载授权。主线使用 Core 接受 PCM 的播放回执；互动排除 ready 状态，衔接语只有 bridge_used=true 后入已播列表。录音主线核对 PCM 引擎的当前片段和消费位置，连续恢复不会重复登记。此记录不恢复场次进度，不启动模型、TTS、开播或缓存复用。

声音沿用原文件及其有效期，通过同房间授权的服务端接口下载；失效后文案仍保留。没有修改声音保留期限或两项平台缓存复用开关。功能上线前已经结束且没有完整播放证据的场次不能补齐；不将历史候选冒充已播文案。

整合到近期运行源码 b58c9cc，保留称呼多样化、P0 与供料修复；未部署模型思考开关分支。发布从实际 current 的完整文件副本开始，只替换 Management、web/web-desktop 入口及新增哈希资源，Core、网关、母版和其它文件逐项保留。

验证：新下载单元测试通过；通过临时 MySQL 表调用实际 Store 方法，验证未播放过滤、文本不可覆盖、到期、半开时间区间、租户/房间/场次隔离与幂等，不修改业务记录；前端构建及原有 14 项回归通过。真实 RoomDetailView 的浏览器合成数据测试覆盖 151 条整场导出、分页、UTC 转换、固定场次、单条音频、过期、错误、焦点恢复和 1600/1024/390/320 宽度。
