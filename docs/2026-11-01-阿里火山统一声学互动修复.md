# 阿里、火山统一声学互动插播

2026-11-01。状态：本地实现并验证中，尚未发布。

第596场欢迎正文和TTS已经成功，但阿里整段主线没有字幕，Core仍要求字幕句末，任务反复排队到过期。用户要求停止监控、修复上线，并进一步明确：阿里和火山统一按音频停顿切，不再通过语义或文字标点找切点。

本轮正式直播入口统一使用实际规范PCM的声学点，不区分TTS厂商、有无字幕和互动任务类型。Core将即将播放的同一份下载暂存到有上限的临时文件，按同一24kHz单声道PCM16规范扫描，保留源PCM SHA256、样本数与算法版本。播放读取该份临时内容，不为扫描额外下载一次，不增加模型输入或TTS采购。临时文件播放结束、取消或失败时关闭删除，不修改付费原始缓存。每个源/PCM最多32MiB，同时最多4次扫描，扫描完成释放PCM大缓冲。

采用20ms能量帧，至少60ms连续低能量邻域，结合全段、局部和绝对能量上限，排除短暂过零。A深停顿优先，窗口内没有A时选B低谷；切点落在停顿内部并与20ms输出帧对齐。毫秒位置对应24个源采样/毫秒，本实现验收为帧对齐切点及等长2ms淡变，不承诺任意过零采样精度。字幕只按播放PTS展示，不授权切点；无停顿就继续排队，沿原TTL/配额处理，不强切发声。

正式直播按当前节目、版本、轨道、任务和PCM表验证切点。每次提交最多向前30秒，并受原任务有效期约束；切点已过、换段、停播等继续走已有冲突/重调度合同。已准备的音频不因找不到停顿而重新生成。没有新增宽限期，没有改欢迎/语义/下单等原有TTL和频率。

使用明确的声学模式标志，不能用“存在SwitchAtMS”推断模式。切入与恢复位置相等；声学模式绕过旧句子单元挑选、跳句、去重和桥接，不消耗未播主线。取消等待释放保留点继续原主线；真正插播后保留恢复游标，结束/失败恢复沿原任务归属校验进行。付费音频不变，淡变只作用于输出副本。

验证包括：不同音量、短过零和连续停顿、A/B与期限筛选；带字幕/无字幕同一声学点；原始PCM覆盖与精确续播；取消时完整主线；有句末字幕但无停顿时拒绝；共同HTTP入口欢迎/问答；真实Core消息与互动完成回执；既有换段、重开、暂停、重试与过期守卫。
