## 四、记录规范

1. 发布 ID 与生产目录一致，不另起别名。
2. “已上线”必须有健康检查、冒烟和回执；只有源码/构建不算。
3. 回滚目标写实际前驱，不写“上一版”这种模糊说法。
4. 未验证项单独写“未验证”，不写成通过。
5. 同一发布被后续覆盖时，保留原记录，新增一条后继记录。
