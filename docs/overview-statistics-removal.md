# 概览统计展示统一移除（2026-09-24）

## 本轮范围

用户明确：不只是财务，系统所有类似概览统计卡、统计条均移除，后续另定展示方案。本轮不建设替代图表，不用 CSS 隐藏继续后台取数。

已移除共用功能首页的统计区及专用取数逻辑。系统总览、组织架构、客户、销售工作台/线索/回访/业绩、营销、直播运维、配额、代理、仓储售后、物流、收款确认、资金权益审批、经营收支、结算等页面的同类汇总卡同步移除。标题下直接保留功能入口或具体业务内容，不留下统计区空白。

两个手机端首页移除同类统计卡及专用业务查询。销售手机端原业绩页只有汇总卡，本轮保留路由并明确提示旧展示已移除，未伪装成新报表已完成。

## 保留边界

- 功能导航、真实业务列表/卡片、筛选、排序、分页与列表总条数保持。权限、审核开关、收款确认、资金记录和售后工单动作不改。
- 客户账户余额、会员和时长资产、订单商品金额、出入库 SN 校验、设备与 AI 启停等是业务办理信息，不作为装饰统计删除。直播运维已有的时长卡剩余悬浮提示不改。
- 销售交接的本次确认数量改为简短说明，仍需用户核对；代理退出的阻塞原因、退出权限和清算记录保留。不能因删除统计卡而跳过这些校验。
- 全局财务待办链接属于此前明确要求的业务提醒，继续保留。收款页面重复的统计卡及单独统计请求已移除，真实列表仍刷新。
- 不更改后端接口/数据库；与业务列表共同返回的汇总字段可以继续兼容旧调用方，但前端不再为了已移除统计块保留额外状态或计算。未改变真实客户、资金、审核结果及历史数据。

## 实施方式

跨页清理按当前文件 SHA 检查，保留工作区原有并发修改。`DomainHubView.vue` 移除统计请求，保留权限过滤后的功能入口；`PlatformOverviewView.vue` 仅保留功能导航所需的权限请求。移动首页不再查询客户列表、业绩、直播间或资源仅供统计。

清理不删除功能所需控件：钱包保留充值入口；邀请保留邀请码与复制动作；产品类别切换保留为紧凑按钮，不再展示大数字统计。

## 回归验证

- `node scripts/test-overview-removal.cjs`：静态扫描所有 Vue 模板和两个 Svelte 手机端，检查旧统计块消失，必要控件和数据请求保留。
- `node scripts/test-customer-business.cjs`：独立 Chrome、全部业务 API 模拟；覆盖八个模块首页无统计区/无空白占位/无专用统计查询、两个手机首页，以及收款、权限开关、工单、资金分页和 18px/蓝光交互。
- Vue 类型检查和生产构建；两个手机端各自 `pnpm run check` 与生产构建。

销售手机端检查发现原共享工单组件读取 `actor.tenant_id`，而销售端 Actor 类型遗漏该可选字段；本轮补充可选、可为空的类型声明，与 bootstrap 数据结构对齐，不更改运行逻辑或权限。

测试不使用真实员工账号，不审核或修改真实账款。本轮不重启后台、不开关看门狗、不提交或推送 Git。生产构建原有的大包告警与本次展示移除无关，不以修改告警阈值掩盖。
