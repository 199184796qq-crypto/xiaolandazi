# 事实归属表头归类排序

归属范围表头点击按公共、商品链接自然数字顺序归类，再次点击倒序，第三次恢复后台返回的原顺序；箭头和aria-sort说明当前状态，支持键盘。相同归属内保持原顺序，序号和隔行底色跟随显示列表，不改变事实ID、数据库顺序或生成/保存方案上下文。未知归属及原商品不可用项始终在末尾，租户/方案不匹配的商品不参与关联。

排序仅在当前页面生效，切换房间、方案或账号恢复原顺序；归属保存成功后自动调整显示位置，失败仍保留原归属。编辑或保存时禁用表头排序按钮。普通web与桌面独立源码同步，桌面继承e17c272，保留之前去分类栏、序号、事实归属、字段改名和WorkBuddy改动。字体至少16px；不改后台、客户事实或方案，不重启服务，不写E:/speech-generator-build。验证及上线结果按实际证据补记，证据work/fact-scope-sort-proof。

普通web和桌面类型检查、生产构建通过。两份真实LiveStrategyView父级合成验收均通过：公共/1号/2号/10号的自然排序、同组稳定、键盘正序/倒序/恢复、排序不写接口、归属保存后重新归类、编辑时禁用、方案切换复位；原归属保存/刷新/失败回退/失效重选/迟到回执及四列展开、连续序号、1600/1024/390/320px无页面溢出、16px和三个按钮同排均通过。所有交互为本地合成数据，未写生产资料或调用模型/TTS。
