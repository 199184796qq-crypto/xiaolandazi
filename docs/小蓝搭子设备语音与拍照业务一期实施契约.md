# 小蓝搭子设备语音与拍照业务一期实施契约

日期：2026-10-02。状态：代码、固件构建与服务端发布完成；待用户实机验收，不以编译通过代替实机验收。

后续双词唤醒、回应称呼和独立提示音以[二期交付说明](小蓝搭子双唤醒与语音反馈二期交付.md)为准；本文件保留一期接口边界和历史发布记录。

## 1. 用户范围

- 品牌和开机、配网、添加设备提示统一为“小蓝搭子”。默认名称“小蓝搭子”“小蓝搭子02”，保留用户自定义名称。
- 房间显示“直播间 名称（#15房间号）”，其中编号使用业务房间号，长名称换行；不拿数据库内部 ID 代替业务房间号。未配置名称或编号时诚实降级。
- “小蓝，音量调整到30%”“百分之三十”；大/小一点 ±10；静音/取消静音/查询音量。
- 字体大/小一点、恢复默认；小/中/大三档只能映射到确实打包可用的字体资源。
- “小蓝，看下环境”“拍张照片”：当时单张快照上传到本项目服务器，创建业务接收事件。本期不自动识图、不运行视频流。
- 主键 GPIO0 短按语音输入，副键 GPIO46 短按静音/恢复；不能凭外壳照片断言上下映射，实机日志确认。
- 两键在已开机状态重叠按住满 5 秒，倒计时；提前松任一键取消。满 5 秒提示松手，松手后执行清设置并重启。组合抑制单键功能，绝不要求按住键开机。

## 2. 恢复设置的数据边界

清除已保存 Wi-Fi、用户音量/静音/字体等设置，并持久提交；重新启动配网。

保留当前固件、OTA 槽及 otadata、字体/唤醒资源、硬件 MAC、board.uuid、服务器配置。不得全片擦除、不得使用会清除 otadata 的原工程 ResetToFactory。

不调用云端解除所有权/房间解绑，不改库存、客户账号、设备销售记录或小蓝豆余额。恢复本机设置不等于转让设备。

## 3. 设备控制协议

设备常驻已鉴权 WebSocket，独立、有界命令会话，不调用原关闭 WebSocket 的聊天切换路径。

- 上行：现有 `listen` start/detect/stop 和 mono Opus 音频，网关保留采样率信息并包装合法 Ogg。单句最长 8 秒，有包大小/并发/频率上限。
- 网关反馈：`control_status`，`request_id`，`state` = listening/processing/error/done，`message`。
- 下行：`device_control`，`request_id`，`action` = volume/font_size/capture，`operation` = set/adjust/mute/unmute/query/reset，`value`。
- 音量 value：set 0–100，adjust ±10；相对操作在盒子按实际值计算。
- 字体 value：0/1/2 对应小/中/大；adjust ±1。固件可兼容 small/medium/large 字符串。
- 拍照附 `upload_url`，短期设备级授权 URL；无管理内部凭据、无永久存储密钥。
- 回执：`device_control_ack`，相同 request_id/action，status = success/error，value 为实际结果，message。
- 固件请求幂等，网关有回执超时；没有回执不宣称成功。含糊指令、越界值或未知动作不执行。

录音期间仅暂停/压低本机输出，不停止 Core 房间任务、不把确认语音加入房间音轨。控制提示暂时优先于五秒状态刷新和字幕；结束后恢复正常显示和播放。不能仅打开 VoiceProcessing 导致清空播放队列。

## 4. 服务端接口

以下内部接口只接受已配置的 `X-Xiaozhi-Internal-Token`；网关在可信头传 `X-Device-MAC` 和 `X-Request-ID`。服务器从实际设备归属解析租户和房间，不信任盒子自报 tenant_id。

| 接口 | 用途 |
| --- | --- |
| POST /internal/v1/xiaozhi/voice | 短录音 multipart file，ASR 返回文本及事件编号；不进入业务大模型 |
| POST /internal/v1/xiaozhi/capture | JPEG multipart file，验证大小/格式、私有存储、创建 queued 快照业务事件 |
| POST /internal/v1/xiaozhi/command-dispatch | 原子记录首次下发权限，recognized → executing；同一请求只准下发一次，网关重启不重放 |
| POST /internal/v1/xiaozhi/command-events | 记录控制的实际回执、失败或超时；action/operation 白名单 |
| GET /api/v1/live/devices/{deviceID}/business-events | 用户仅查询自己设备事件，图片访问仍受租户授权 |
| GET /internal/v1/xiaozhi/business-events?tenant_id=…&limit=20 | 查询当前归属仍有效的 queued 环境快照，使用 before_id 游标翻页 |
| GET /internal/v1/xiaozhi/business-events/{eventID}/image | 可信业务进程下载私有照片，附内部 token 和 X-Device-MAC；无公开图片地址 |
| POST /internal/v1/xiaozhi/business-results | 提交 succeeded/failed 和 result_text，按设备、租户和 request_id 幂等 |

公网 `POST /xiaozhi/v1/capture?grant=...` 由网关验证短期上传授权（设备/会话/请求/期限），再代理到内部快照接口；不得开放无鉴权上传、不暴露服务器内部 token。

照片最大 2 MiB、限制 JPEG 像素尺寸；语音最大 2 MiB。语音临时文件用后删除，图片为私有对象；返回事件/接收编号，不返回公开永久图片链接。

## 5. 小蓝豆和幂等

本期语音控制和图片业务均记录服务端使用事件，`billing_mode=disabled`、`charged_beans=0`，不调用钱包扣款。不擅自确定价格。后续授权/报价/扣款/退款全部在服务器完成，盒子没有余额和扣豆逻辑。

事件按设备、租户、request_id、business_type 唯一。语音和快照可以共享请求编号，但不是同一业务事件。失败/超时终态不能因重试变为成功，重传不能重复创建扣费。上传回执成功只代表已接收，快照 queued 不代表分析已完成。

下发前服务器持久记录 executing，即使网关硬重启也不能重放同一条相对指令。记录成功但网络中断时可能没有执行，按失败处理；不冒险重发，用户可以明确发起一条新的请求。

本机按键和恢复设置可以离线使用，不产生服务器扣费。

## 6. 验收门槛

1. 固件静态/主机逻辑测试、ESP-IDF 编译、完整包地址/分区核验；实机另验。
2. 语音数字、中文数字、前导百分号表达、模糊/越界/未知、无回执和重复请求回归。
3. 上行 Opus 可解码，listen/abort 不断开常驻业务连接，8 秒和包大小限额有效。
4. 双键 4.9 秒松开不重置，满 5 秒一次触发，组合不录音/不静音，重启后仍当前固件且仅用户配置被清除。
5. 静音重启保留；调整后 ACK 与实际音量一致；字体三档切换可读。
6. 单图可在服务器查到对应设备/租户/房间事件；无权、过期、篡改、超大图片和重复上传被正确处理；实际扣豆为零。
7. 小蓝唤醒模型真实打包；播报环境误唤醒率、连续一句话不丢开头、相机方向/色彩和语音并发均实机验证。
8. 发布只替换必要服务和前端，不改 Core、库存真实数据及云端归属。备份与可回滚、健康检查不能代替上述业务实机验收。

后续持续视频属于另一期。可从低帧率 JPEG/MJPEG 连续帧研究，必须有显式开启/停止、期限、授权及计费策略；本期默认不采集/上传持续影像。

## 7. 外部识别依赖核验

复用服务器已有 `qwen-audio-3.1-asr-flash-filetrans`，上传有效 Ogg/Opus 单句音频并走异步提交、查询结果。这是有超时的文件识别，不承诺实时识别延迟；以后要降低延迟可以另做实时 ASR，不能在本期伪装已经实现。

模型输入格式与异步流程依据：[阿里云语音模型输入规格](https://help.aliyun.com/zh/model-studio/asr-model)、[阿里云文件识别 HTTP 接口](https://www.alibabacloud.com/help/en/model-studio/fun-asr-recorded-speech-recognition-http-api)。

## 8. 后续业务处理接入

业务进程在服务器内调用队列接口，不从盒子取得租户信息或存储密钥。每次提交结果需附 `X-Xiaozhi-Internal-Token`、`X-Device-MAC`、`X-Request-ID`；示例结果体：

```json
{"status":"succeeded","result_text":"业务处理结果"}
```

本期队列只表示已经交付照片和事件，不启动后台分析器、不向房间音轨加入结果语音。以后在这一服务端边界增加小蓝豆的授权、报价、扣款与失败退款，设备协议无须加入余额字段。
