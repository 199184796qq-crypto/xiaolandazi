# sales-mobile

销售人员轻量手机端，基于 SvelteKit + TypeScript。

## 边界

保留：
- 销售工作台
- 我的客户
- 产品 / 会员 / 时长 / 设备方案入口
- 我的业绩与提成
- 邀请与通知入口
- 小蓝工作搭子

明确不开放：
- 客户充值
- 退款与奖励发放
- 财务审批 / 结算
- 系统设定
- 修改商品、会员、佣金和营销规则
- 查看超出本人岗位范围的客户

智能体调用 `/api/v1/internal-agent/*`，但仍由服务端按销售岗位权限和业务范围裁剪能力。

## 本地启动

```bash
pnpm dev
```

推荐地址：`http://sales.localhost:5175/`

访问 `http://127.0.0.1:5175/` 或 `http://localhost:5175/` 时会自动跳转到独立的 `sales.localhost` 主机名，避免与管理后台共享同名登录 Cookie。

开发环境将 `/api` 代理到 `http://127.0.0.1:8080`。
