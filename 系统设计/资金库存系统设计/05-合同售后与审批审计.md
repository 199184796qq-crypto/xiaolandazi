# 05 合同、售后、审批与审计

## 一、合同类型

至少支持：

- 代理合作合同
- OEM 合同
- 设备采购合同
- 设备销售合同
- 客户服务合同
- 补充协议
- 续签协议
- 解除协议

## 二、合同不可删除

合同状态：

草稿
-> 待签署
-> 已签署
-> 生效
-> 即将到期
-> 已到期
-> 终止
-> 作废

“作废”不是删除。

已正式产生的合同永久保留。

## 三、合同快照

合同签署时固定：

- 签约主体
- 代理等级
- 采购政策
- 返佣政策
- 结算周期
- OEM 权限
- 区域
- 保修政策
- 附件文件哈希

后续政策变化不反写历史合同。

## 四、补充协议

历史合同发生变化时，只能新增：

- 补充协议
- 变更协议
- 续签合同
- 解除协议

原合同保持原样。

## 五、售后 RMA

统一售后单 RMA。

入口可能来自：

- 客户
- 代理
- 总部客服
- 仓库异常签收

售后类型：

- 退货
- 换货
- 维修
- 补发
- 退款
- 运损理赔

## 六、售后流程

申请
-> 初审
-> 上传故障证据
-> 判断保修
-> 生成退回物流
-> 售后仓收货
-> 检测
-> 结论
-> 维修/换新/退货/报废
-> 新物流
-> 客户或代理签收
-> 关闭

每一步产生设备状态和库存流水。

涉及退款时联动资金系统，但不能由售后模块自己直接改余额。

## 七、保修

按产品策略配置：

- 起算点
- 保修期
- 免费范围
- 人为损坏范围
- 收费规则
- 运费承担
- 换新条件
- 延保

起算点可选择：

- 总部发货
- 代理签收
- 客户签收
- 设备激活

## 八、统一审批中心

不要每个模块自己实现审批。

审批中心统一管理：

- 代理开户
- 代理升级降级
- 特殊采购价
- 退款
- 调账
- 提现
- 结算
- 提成
- 客户转移
- 库存盘亏
- 设备报废
- 换机
- 合同变更
- 银行账户变更

## 九、审批策略

支持：

- 单级
- 多级
- 金额阈值
- 按组织
- 按角色
- 会签
- 或签
- 经办审核分离

关键财务和库存业务应默认“经办人 != 最终审核人”。

## 十、审计记录

每个关键动作至少记录：

- 操作人 employee_id
- 当时姓名
- 当时组织
- 当时部门
- 当时岗位
- 动作
- 原值
- 新值
- 原因
- 时间
- 关联单据
- 审批单
- 附件
- 风险来源

员工改名、调岗、离职后，历史审计不变化。

## 十一、附件证据

发票、合同、物流证明、签收照片、故障照片、银行回单等附件应保存：

- 文件 ID
- 文件哈希
- 上传者
- 上传时间
- 关联业务

防止附件被无痕替换。

## 十二、删除策略

以下对象原则上只做逻辑状态变化，不做物理删除：

- 已支付订单
- 支付流水
- 退款单
- 结算单
- 提现单
- 提成单
- 入库/出库单
- SN 记录
- 盘盈盘亏
- 报废
- 售后
- 已签合同
- 客户归属历史
- 审批记录
- 审计日志
