# 04 代理、销售、客户与 OEM

## 一、代理档案

代理至少包含：

- 代理组织
- 当前商业等级
- 上级代理
- 区域
- 独家/非独家
- 合同状态
- OEM 权限
- 结算状态
- 风险状态
- 采购权限
- 提现账户状态

状态：

待审核
-> 待签约
-> 正常
-> 暂停
-> 冻结
-> 合同到期
-> 退出处理中
-> 已退出

## 二、代理升级降级

不修改历史等级字段。

使用 AgentLevelHistory：

- old_level
- new_level
- approved_at
- effective_at

生效日前订单使用旧规则，生效日后使用新规则。

## 三、代理采购

代理在自己后台采购设备。

系统读取：

代理当前等级 + 生效采购价格政策

形成采购订单。

代理付款后进入总部发货和代理入库流程。

设备采购和终端会员消费是两种不同资金逻辑。

## 四、代理设备销售

代理可根据总部授权自行决定终端设备销售价。

客户付款仍可统一进入总部支付体系。

系统根据设备所有权/库存来源，确认代理对应设备销售收入。

设备销售结算不能套用会员返佣比例。

## 五、消费会员

会员体系总部统一：

- 会员名称
- 售价
- 权益
- 有效期
- 服务范围

代理不可修改。

客户从哪个渠道购买，只影响代理/销售结算，不改变会员本身定义。

## 六、代理内部组织

每个代理可以建立：

代理管理员
-> 财务部
-> 销售部
-> 仓储组
-> 售后组

总部授予权限上限。

代理内部不能创建超出总部上限的角色。

## 七、销售体系

销售分两类：

- 总部内部销售
- 代理内部销售

销售只能查看自己权限范围内客户和业绩。

销售默认不能：

- 人工改钱包
- 发放奖励
- 审批自己提成
- 修改财务结算
- 修改设备库存

## 八、客户资源

客户来源至少包括：

- 总部自然注册
- 总部销售
- 代理自然客户
- 代理销售
- 邀请二维码
- 销售链接
- 设备激活
- 人工导入
- 活动来源

客户主档和归属关系分离。

## 九、撞客

客户唯一性可使用：

- 手机号
- 实名主体
- 企业统一社会信用代码
- 设备绑定
- 其他业务唯一键

撞客进入 ConflictCase。

不能由销售私下覆盖。

处理后产生归属关系历史。

## 十、客户转移

客户转移：

申请
-> 审批
-> 旧关系结束
-> 新关系生效

旧订单、旧提成、旧结算仍归原历史关系。

## 十一、销售离职

离职不能删除员工。

状态改为离职/停用。

处理：

- 未跟进线索转移
- 在跟客户转移
- 历史订单保留原销售快照
- 已产生提成保留
- 未结提成按公司政策继续或终止

## 十二、代理退出

退出不是简单禁用。

必须清算：

- 剩余设备
- 在途设备
- 开放售后
- 客户归属
- 未结算金额
- 风险准备金
- 负余额
- 销售提成
- OEM 品牌
- 合同
- 提现账户

完成 ExitSettlement 后才能进入“已退出”。

## 十三、OEM

OEM 允许代理配置：

- 品牌名
- Logo
- 登录页
- 域名
- 联系方式
- 客服
- 协议
- 页面主题

OEM 只改变品牌呈现和授权视图，不改变底层真实资金主体和设备归属。

租户隔离必须从底层组织字段实施。

代理 A 不能看代理 B 的员工、客户、设备、订单、资金、合同、售后。
