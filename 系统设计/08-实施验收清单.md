# 08 实施验收清单

以下项目建议作为产品、开发、测试共同验收条件。

## A. 组织与权限

- [ ] 总部与代理统一组织模型
- [ ] 代理等级和上下级分离
- [ ] 部门、岗位、员工可配置
- [ ] 代理权限不超过总部授权上限
- [ ] 高风险业务支持经办/审核分离
- [ ] 员工离职不删除历史
- [ ] 操作人保留组织岗位快照
- [ ] 超级系统管理员名称统一，系统配置权与财务审批权分离
- [ ] 系统内置基础部门锁定，自定义部门可新增；部门负责人只能在权限上限内新增/管理本部门员工
- [ ] 管理部可查看整体组织架构但不会因此自动获得修改其他部门权限定义的能力
- [ ] 功能权限和数据范围分离，后端强制校验
- [ ] 销售只能查看本人/本团队授权客户和业绩，不能改资金、发奖励或审批自己提成

## A2. 账号与安全

- [ ] 系统创建客户/代理/员工账号时随机生成初始密码
- [ ] 初始凭据仅一次性展示/复制或通过已验证邮箱交付
- [ ] 首次登录强制改密，临时密码有失效时间
- [ ] 管理员只能重置密码，不能查看原密码
- [ ] 凭据交付、重置和高权限变更有审计日志

## B. 产品

- [ ] 设备、会员、服务采用不同结算类型
- [ ] 会员价格和权益由总部统一
- [ ] 设备代理采购价按等级/政策
- [ ] 代理可以在授权范围内自定终端设备价
- [ ] 产品和结算规则版本化
- [ ] 历史订单保留规则快照
- [ ] 会员方案、时长卡、推荐奖励分别版本化
- [ ] 一级推荐奖励支持退款冲回规则

## C. 客户

- [ ] 客户主档和商业归属分离
- [ ] 支持自然客户、销售客户、代理客户
- [ ] 支持撞客处理
- [ ] 支持客户转移审批
- [ ] 历史订单不随客户转移重新归属
- [ ] 销售离职后客户可转移，历史不变
- [ ] 自然注册直营客户默认不归属具体销售
- [ ] 销售链接/二维码注册保存销售归属快照
- [ ] 省、市、区/县三级下拉必填并保存区域代码和版本

## D. 代理

- [ ] 等级、区域、合同、采购政策可独立配置
- [ ] 升降级有生效时间
- [ ] 月中升级不影响历史订单
- [ ] 代理退出有清算流程
- [ ] OEM 数据隔离
- [ ] 代理提现账户变更需审批

## E. 设备库存

- [ ] 每台设备有唯一 SN
- [ ] 支持批次
- [ ] 所有权、保管地、使用者分离
- [ ] 所有货动有正式单据
- [ ] 支持锁库
- [ ] 支持拆包/多包裹
- [ ] 支持部分签收
- [ ] 支持拒收、短少、破损
- [ ] 支持退货、维修、换机
- [ ] 支持翻新
- [ ] 支持盘盈盘亏
- [ ] 支持报废
- [ ] 库存余额可由流水重算
- [ ] 可按任意时间点重建库存

## F. 资金

- [ ] 支持收款
- [ ] 支持部分退款
- [ ] 支持全额退款
- [ ] 支持返佣
- [ ] 支持提成
- [ ] 支持冻结/解冻
- [ ] 支持提现
- [ ] 支持提现失败退回
- [ ] 支持负余额
- [ ] 支持跨期抵扣
- [ ] 支持冲正
- [ ] 支持人工调账单
- [ ] 禁止直接改钱包余额
- [ ] 金额使用整数分存储
- [ ] 比例舍入规则统一
- [ ] 支付/退款/提现回调幂等

## G. 结算

- [ ] 按订单行结算
- [ ] 不同产品可用不同规则
- [ ] 结算周期可关闭
- [ ] CLOSED 周期不可回写
- [ ] 跨期退款生成新周期调整
- [ ] 支持风险准备金
- [ ] 支持可提延迟
- [ ] 代理结算和销售提成分账

## H. 合同

- [ ] 已签合同不可删除
- [ ] 支持补充协议
- [ ] 支持续签
- [ ] 支持解除
- [ ] 合同保存规则快照
- [ ] 附件保存哈希
- [ ] 合同到期提醒

## I. 售后

- [ ] 统一 RMA
- [ ] 退货
- [ ] 换货
- [ ] 维修
- [ ] 补发
- [ ] 运损
- [ ] 退款联动财务
- [ ] 售后联动库存
- [ ] 换机 old_sn/new_sn 关联
- [ ] 报废审批

## J. 对账

- [ ] 支付渠道对账
- [ ] 退款渠道对账
- [ ] 银行提现对账
- [ ] 代理结算对账
- [ ] 销售提成对账
- [ ] 库存流水对账
- [ ] 实盘对账
- [ ] 差异自动形成差异单
- [ ] 差异平账有审批和凭证

## K. 追溯

- [ ] 任意支付可追到客户、订单、代理、销售
- [ ] 任意提现可追到所有资金来源
- [ ] 任意退款可追到原支付
- [ ] 任意结算可追到订单行
- [ ] 任意 SN 可追全生命周期
- [ ] 任意库存调整可追到原差异
- [ ] 任意人员可查经办/审核记录
- [ ] 任意业务有 business_trace_id
- [ ] 支持“以人查事”和“以事查人”

## L. 异常与可靠性

- [ ] 重复支付回调不重复记账
- [ ] 重复退款回调不重复退款
- [ ] 重复提现点击不重复付款
- [ ] 重复发货操作不重复出库
- [ ] 支付成功但内部处理失败可补偿
- [ ] 外部渠道成功、系统未知可通过对账恢复
- [ ] 所有补偿操作有审计

只有以上关键项通过，系统才算完成“闭环可追溯”。
