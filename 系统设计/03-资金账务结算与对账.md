# 03 资金账务结算与对账

## 一、资金系统目标

必须完整支持：

进、退、抵、分、冻、解、提、冲、调、平

即：

- 收款
- 退款/部分退款
- 抵扣
- 返佣/结算
- 销售提成
- 冻结
- 解冻
- 提现
- 提现失败退回
- 冲正
- 调账
- 差异平账
- 负余额与跨期抵扣

## 二、四本账

### 1. 业务单据账

记录为什么发生。

### 2. 支付渠道账

记录微信、支付宝、银行等真实外部流水。

### 3. 内部资金总账/分户账

记录总部、代理、销售钱包、待结算、冻结等账户之间的变化。

### 4. 结算账

记录某一业务按规则应该给代理和销售多少钱。

任何“余额”都只是流水汇总结果。

## 三、资金账户建议

总部侧：

- 现金/银行账户
- 支付渠道在途账户
- 待结算账户
- 总部收入账户
- 支付手续费账户
- 退款准备账户
- 差异待处理账户

代理侧：

- 待结算
- 风险冻结
- 可用
- 可提现
- 已提现
- 负余额

销售侧：

- 待确认业绩
- 待审核提成
- 冻结提成
- 可提现
- 已提现
- 追缴/负余额

## 四、客户支付

客户支付成功后：

1. 保存 Payment。
2. 写支付渠道流水。
3. 写内部资金流水。
4. 根据订单产品分别计算结算。
5. 生成 AgentSettlementAccrual。
6. 生成 SalesPerformance。
7. 进入待结算，而不是立即可提现。

一个订单有多种产品时，必须逐订单行分别采用相应结算规则。

## 五、代理风险准备金和可提延迟

为避免“代理已全部提现，客户后续退款导致总部垫钱”，代理等级政策可配置：

- settlement_hold_days
- reserve_ratio
- minimum_reserve
- withdrawal_delay_days

例如应结算 10 万：

- 风险冻结 5%
- 其余满足 T+N 后进入可提现

后续退款先冲减未结算和风险金，不足再形成负余额。

## 六、退款和冲正

退款必须绑定原支付：

Refund
-> Payment
-> Order
-> OrderLine
-> Product
-> Agent
-> Sales
-> SettlementRuleSnapshot

部分退款按原订单行和原结算规则反向计算。

已经完成月结也不能修改旧周期。

在新周期生成：

- 代理结算调整 -X
- 销售提成调整 -Y
- 总部收入调整 -Z

## 七、负余额

如果代理或销售已提现，退款导致追缴：

balance < 0

系统允许生成负余额，但禁止继续提现。

后续结算优先抵扣负余额。

每一笔抵扣都必须指出对应的原退款/原冲正。

## 八、销售提成

销售提成与代理结算是两层账，不能混在一个字段。

代理结算：

总部欠代理多少钱。

销售提成：

代理或总部内部欠销售多少钱。

销售提成可按：

- 固定金额
- 比例
- 阶梯
- 月度目标
- 首单
- 续费
- 团队
- 主管分润

所有方案版本化。

## 九、提现

流程：

申请
-> 校验可提现余额
-> 资金冻结
-> 财务初审
-> 复核
-> 付款
-> 银行/三方结果
-> 成功入账

失败：

付款失败 -> 解冻 -> 返回可提现

驳回：

审核驳回 -> 解冻

绝不允许失败后资金一直悬挂。

## 十、人工调账

禁止直接改钱包余额。

人工调账必须：

发起 AdjustOrder
-> 原因
-> 附件
-> 审核
-> 复核
-> 产生正式 LedgerEntry

调账也必须进入对账和审计。

## 十一、幂等

下列业务都必须带业务幂等键：

- 支付回调
- 退款回调
- 提现请求
- 结算生成
- 提成生成
- 银行付款回执
- 调账入账

重复回调只能返回原结果，不允许重复记账。

## 十二、金额精度

统一币种 CNY 时建议金额以“分”为最小整数单位存储，避免浮点误差。

比例计算必须统一：

- 舍入规则
- 舍入位数
- 差额归属

并将计算明细保存。

## 十三、对账中心

至少有六类对账：

1. 系统支付 vs 支付渠道
2. 系统退款 vs 渠道退款
3. 系统付款/提现 vs 银行流水
4. 订单 vs 代理结算
5. 销售业绩 vs 提成 vs 钱包
6. 系统库存 vs 库存流水 vs 实盘

差异进入 ReconciliationCase。

处理流程：

发现差异
-> 锁定
-> 调查
-> 上传依据
-> 审批
-> 生成调整单
-> 重新对账
-> 平账

## 十四、月结

月末不是“算完就改余额”，而是：

生成结算草稿
-> 自动校验
-> 代理确认/异议
-> 财务审核
-> 锁定结算单
-> 周期关闭
-> 进入可提规则

CLOSED 周期任何历史数据不回写。
