# 06 追溯中心与穿透查询

## 一、系统级 Trace Center

追溯能力不是财务和仓库各自做一套，而是底层统一 Trace Center。

所有关键业务共享 business_trace_id。

同时记录节点之间的关联边：

- ORDER_CREATED
- PAYMENT_SUCCESS
- STOCK_RESERVED
- STOCK_OUT
- LOGISTICS_SHIPPED
- AGENT_RECEIVED
- DEVICE_BOUND
- SETTLEMENT_ACCRUED
- COMMISSION_ACCRUED
- REFUND
- REVERSAL
- WITHDRAWAL
- RMA
- REPLACEMENT
- SCRAP

## 二、财务一键资金全链

任何一笔钱点“资金全链路”后展示：

原始业务
-> 付款人/充值人
-> 订单
-> 产品
-> 支付渠道
-> 实际到账
-> 所属代理
-> 所属销售
-> 适用规则版本
-> 代理应结算
-> 销售提成
-> 风险冻结
-> 月结
-> 抵扣/冲正
-> 提现
-> 最终收款账户

每个节点显示：

- 时间
- 金额
- 业务类型
- 单据号
- 经办人
- 审核人
- 复核人
- 付款人
- 收款人
- 充值人
- 提款人
- 所属组织
- 渠道流水号
- 规则版本
- 审批意见
- 附件

## 四、以人查事

搜索一个员工，可查指定周期内：

- 经办的充值
- 审核的退款
- 复核的提现
- 操作的库存
- 经办的出库
- 审批的报废
- 修改的客户关系
- 处理的售后
- 签署/经办的合同

用于责任追踪和内部风控。

## 五、以事查人

搜索一笔资金：

发起人 -> 经办人 -> 审核人 -> 复核人 -> 实际付款人 -> 收款人

搜索一台设备：

入库人 -> 拣货人 -> 复核人 -> 出库人 -> 签收人 -> 售后人 -> 报废审批人

## 七、历史重建

系统必须支持“时间点重建”。

例如：

2026-10-31 23:59:59 时：

- 某代理库存多少
- 可用多少
- 在途多少
- 待结算多少
- 风险冻结多少
- 可提现多少
- 负余额多少

实现依据是不可变事件/流水 + 生效时间，而不是当前表里一个最终数字。

## 八、权限

Trace Center 不是人人可看全部。

- 总部财务：可看资金全链，但设备细节按授权。
- 总部仓储：可看设备链，但银行账户敏感信息脱敏。
- 代理财务：只看本部门织资金。
- 代理仓储：只看本部门织设备。
- 审计/超级系统管理员：按系统审计权限查看跨域链路。

敏感字段按角色脱敏。
